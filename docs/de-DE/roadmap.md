# Produkt-Epics

Das GreenER-Backlog gruppiert User Stories in sechs Epics. Akzeptanzkriterien und Aufgaben stehen in den verknüpften Issues; den aktuellen Status bitte direkt auf GitHub prüfen.

| Epic | Umfang |
| --- | --- |
| [EP01 — Anwendungskatalog](https://github.com/Seliganessecodigo/ABP-3DSM/issues/1) | Überwachte Anwendungen anzeigen und durchsuchen. |
| [EP02 — Anwendungsüberwachung](https://github.com/Seliganessecodigo/ABP-3DSM/issues/2) | Erkennung, Lebenszyklus, Status und Datenerfassung. |
| [EP03 — Berechnung der Umweltauswirkungen](https://github.com/Seliganessecodigo/ABP-3DSM/issues/3) | Energie und CO₂e mit nachvollziehbaren Methoden und Einschränkungen schätzen. |
| [EP04 — Umwelt-Dashboard](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4) | Zusammenfassungen und aggregierte Kennzahlen nach Zeitraum. |
| [EP05 — Analyse und Simulation](https://github.com/Seliganessecodigo/ABP-3DSM/issues/5) | Anwendungen vergleichen und regionale Szenarien simulieren. |
| [EP06 — Konfiguration und Administration](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6) | Überwachung mit Berechtigungen konfigurieren und verwalten. |

## Produktprinzipien

- Fehlgeschlagene oder fehlende Beobachtungen werden niemals als Verbrauch von null interpretiert.
- Energie und CO₂e behalten Einheit, Zeitraum, Abdeckung und Kontext.
- Änderungen an Konfiguration oder Methodik dürfen historische Ergebnisse nicht überschreiben.
- Das öffentliche Dashboard benötigt keine Anmeldung; administrative Änderungen werden vom Backend autorisiert.
