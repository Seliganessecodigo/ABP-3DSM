## Ablauf und Validierungskriterien

| Story | Szenario und erwartetes Ergebnis |
| --- | --- |
| US-02 | Neue ID einmal; erste Abwesenheit im vollständigen gültigen Snapshot bestätigt Entfernung; Rückkehr mit Identität/Historie, ohne Lückenfüllung. |
| US-03 | Zustand, Grund, Zeit; Verfügbarkeit/Aktualität/Berechenbarkeit unterscheiden, Text/Icons statt nur Farbe. |
| US-04 | Ohne Reload/Filter-/Seiten-/Identitätsverlust aktualisieren; alte Antwort ersetzt keinen neuen Kontext; Polling unabhängig von Sammlung. |
| US-05 | App-/Quellfehler hebt andere Erfolge nicht auf; Beobachtung bewahren, mit gültigen Belegen erholen. |

Ungültige Nutzlast, Timeout/Fehler bestätigen keine Entfernung. Metrik-404 mehrdeutig. Integration/Speicherung vorausgesetzt; Timeout/Retry/Parallelität/Verzögerung brauchen Freigabe.
