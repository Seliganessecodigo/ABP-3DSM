## Récits utilisateur

| Issue | Capacité |
| --- | --- |
| [US-10 · Synthèse environnementale](https://github.com/Seliganessecodigo/ABP-3DSM/issues/16) | Consulter les totaux agrégés et les indicateurs de la période choisie. |
| [US-11 · Détail d’une application](https://github.com/Seliganessecodigo/ABP-3DSM/issues/17) | Examiner l’état, la localisation, les métriques et les résultats environnementaux. |

Les issues liées font autorité pour les critères d’acceptation, les tâches, les dépendances et le statut. Cette page décrit le périmètre produit, pas l’état de l’implémentation.
