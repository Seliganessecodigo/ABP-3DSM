## Parcours et critères de validation

| Histoire | Scénario et résultat attendu |
| --- | --- |
| US-01 | Ouvrir, rechercher/filtrer, aller au détail avec la même identité. Aucune application : vide ; défaillance API/source : erreur ; aucun résultat filtré n’efface pas le catalogue. |

Ville nullable ; code régional, pays, région et coordonnées obligatoires selon source. Anciens enregistrements incomplets conservés sans localisation fabriquée.

Catalogue consomme états EP02/preuves EP03 ; lecture sans collecte/calcul. Voir [guide](../guide/monitoring).
