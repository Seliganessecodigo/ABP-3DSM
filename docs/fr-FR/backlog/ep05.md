# EP05 — Analyse et simulation

Aide à prioriser et comparer les applications et à prévisualiser un scénario régional sans modifier les résultats officiels.

[Ouvrir dans le backlog GitHub](https://github.com/Seliganessecodigo/ABP-3DSM/issues/5)

## Récits utilisateur

| Issue | Capacité |
| --- | --- |
| [US-13 · Classer par impact](https://github.com/Seliganessecodigo/ABP-3DSM/issues/19) | Classer les applications par énergie et CO₂e sur la même période. |
| [US-14 · Comparer des applications](https://github.com/Seliganessecodigo/ABP-3DSM/issues/20) | Comparer au moins deux applications avec des périodes, unités et couvertures compatibles. |
| [US-15 · Simulation régionale](https://github.com/Seliganessecodigo/ABP-3DSM/issues/22) | Prévisualiser l’effet d’un autre facteur régional sans modifier l’énergie observée. |

Les issues liées font autorité pour les critères d’acceptation, les tâches, les dépendances et le statut. Cette page décrit le périmètre produit, pas l’état de l’implémentation.
