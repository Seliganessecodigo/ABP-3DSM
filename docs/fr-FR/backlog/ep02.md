## Parcours et critères de validation

| Histoire | Scénario et résultat attendu |
| --- | --- |
| US-02 | ID nouveau une fois ; première absence d’un snapshot complet valide confirme retrait ; retour préserve identité/historique sans combler la lacune. |
| US-03 | État, motif, heure ; distinguer disponibilité/fraîcheur/calculabilité avec texte/icône au-delà de couleur. |
| US-04 | Actualiser sans reload/perte de filtres/page/application ; ancienne réponse ne remplace pas nouveau contexte ; polling distinct de collecte. |
| US-05 | Échec application/source n’invalide pas autres succès ; préserver observation, reprise avec preuve valide. |

Payload invalide, timeout/erreur ne confirment pas retrait. 404 métriques ambigu. Intégration/persistance préalables ; timeout/retry/concurrence/retard à approuver.
