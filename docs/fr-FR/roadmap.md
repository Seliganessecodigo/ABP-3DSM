# Épopées du produit

Le backlog GreenER regroupe les récits utilisateurs en six épopées. Les critères d’acceptation et les tâches restent dans les issues associées ; consultez GitHub pour connaître leur état actuel.

| Épopée | Périmètre |
| --- | --- |
| [EP01 — Catalogue des applications](https://github.com/Seliganessecodigo/ABP-3DSM/issues/1) | Consulter et parcourir les applications surveillées. |
| [EP02 — Surveillance des applications](https://github.com/Seliganessecodigo/ABP-3DSM/issues/2) | Découverte, cycle de vie, états et collecte des applications. |
| [EP03 — Calcul de l’impact environnemental](https://github.com/Seliganessecodigo/ABP-3DSM/issues/3) | Estimer l’énergie et le CO₂e avec des méthodes et limites traçables. |
| [EP04 — Tableau de bord environnemental](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4) | Synthèses et indicateurs agrégés par période. |
| [EP05 — Analyse et simulation](https://github.com/Seliganessecodigo/ABP-3DSM/issues/5) | Comparer des applications et simuler des scénarios régionaux. |
| [EP06 — Configuration et administration](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6) | Configurer et administrer la surveillance avec autorisation. |

## Principes du produit

- Les échecs ou l’absence d’observations ne sont jamais convertis en consommation nulle.
- L’énergie et le CO₂e conservent leurs unités, période, couverture et contexte.
- Les changements de configuration ou de méthode ne doivent pas réécrire les résultats historiques.
- Le tableau de bord public ne nécessite pas de connexion ; le backend autorise les changements administratifs.
