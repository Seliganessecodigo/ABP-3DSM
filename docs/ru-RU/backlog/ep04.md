# EP04 — Экологическая панель

Основа: `origin/develop`, коммит `c343698`, проверено 08.11.2026. Среда может использовать другую ревизию; слияние не доказывает развёртывание.

В `/dashboard` выберите 24 часа, 7, 30 или 90 дней, состояние и регион. Доступны итоги, покрытие, число приложений по состояниям и состав выбросов столбцами/кольцом. Таблица поддерживает поиск, фильтры, сортировку по энергии/CO₂e и страницы; её фильтры не меняют общие итоги. Откройте приложение для проверки свидетельств. `GET /analysis/summary` обновляется периодически без перезагрузки.

В `/history` выберите приложение; `applicationId`, период и детализация сохраняются в URL. Доступны сохранённый ряд, фильтры, часовой пояс отображения, события, нумерованные страницы и проверка интервалов. Вклады имеют интерактивную пагинацию по 5, 10, 15, 20 или всем записям. Интервалы backend остаются в UTC; пояс отображения не перегруппировывает данные. Наложение в подробностях сравнивает то же приложение с предыдущим равным периодом.

В `/administration/calculations` выберите приложение и даты, сравните оригинал/предпросмотр. Конечная дата включает весь день UTC; API принимает `[from,to)`. Публичный предпросмотр использует текущую модель и текущие коэффициенты исторических регионов, ничего не сохраняет. Лимиты: 30 дней, 10 000 наблюдений. Ответ: `original`, `preview`, `warnings`, `status` (`available`, `empty`, `partial`). Ошибка коэффициента сохраняет вычислимую энергию, CO₂e недоступен. Проценты требуют равных единиц/покрытия и положительной базы.

Issues — приёмка/зависимости; Projects — приоритет/Sprint; Figma — визуальная задумка; код/OpenAPI — реальные контракты. Долговременные решения — в ADR. Открытие PR не закрывает issue: подтвердите merge/объём. Исторические ADR сохраняются.
