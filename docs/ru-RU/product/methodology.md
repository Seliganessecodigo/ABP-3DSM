# Методология и данные

Упрощённая модель оценивает энергию по CPU, памяти, диску и сети в интервале наблюдения. Оценённая мощность преобразуется в энергию по длительности. Выбросы равны энергии, умноженной на региональную углеродную интенсивность. Коэффициенты относятся к учебной модели, а не к прямому измерению электричества или официальным региональным факторам. Результат хранит исходную методологию и фактор.

## Понять данные {#vocabulary}

| Понятие | Значение |
| --- | --- |
| Приложение | Сервис с устойчивой идентичностью в каталоге. |
| Наблюдение | Набор метрик для интервала. |
| Энергия | Оценённая величина за период в kWh. |
| Углеродная интенсивность | Региональный фактор в gCO₂e/kWh. |
| Выбросы | CO₂-эквивалент с указанной единицей. |
| Покрытие | Доля периода, подтверждённая корректными данными. |

## Модель оценки {#model}

| Параметр | Величина |
| --- | --- |
| CPU (100%) | 100 W |
| Память | 0.375 W/GB |
| Диск | 0.01 W/GB |
| Сеть | 0.02 W/GB |

```text
P [W] = P_CPU + P_RAM + P_disk + P_network
E [kWh] = P [W] × Δt [h] / 1000
CO₂e [g] = E [kWh] × I [gCO₂e/kWh]
```

## Понять покрытие {#coverage}

Покрытие — доля периода с корректными наблюдениями. У энергии и выбросов оно раздельное: энергия может быть оценена без фактора для вычисления выбросов. Сравнивайте совместимые периоды, единицы и покрытие. Низкое покрытие означает частичный анализ, а не доказанное уменьшение потребления.

Ноль означает, что значение подтверждено корректным наблюдением. Пробел означает отсутствие пригодных данных, а не нулевое потребление. После ошибки обновления может сохраниться последнее корректное значение с исходным временем. Перед решением проверьте актуальность и покрытие. Экраны запрашивают данные через 60 секунд после каждой попытки, не гарантируя новое измерение каждый раз.

## Периоды и история {#history}

| Правило | Значение |
| --- | --- |
| Сохранение истории | Настройки и предпросмотры не заменяют оригиналы. |
| Явное отсутствие | Ошибки, нехватка метрик и старые данные отличаются от нуля. |
| Публичное чтение | Показатели доступны без входа; сохранение настроек и администрирование требуют разрешения. |

В предпросмотре выберите приложение и даты для сравнения оригинала с текущей моделью и текущими факторами наблюдавшихся регионов. Последний день целиком включается в UTC. Допустимы 30 дней и 10 000 наблюдений. Предпросмотр не сохраняется и не меняет историю. Проценты показываются при равных единицах и покрытии и положительном оригинале.

## Настройки для реальных данных {#personal-preferences}

В `/methodology` задайте ограничения энергии и выбросов для каждого приложения, порог покрытия и параметры анализа. Доступны последние 24 часа, 7, 30 или 90 дней, текущий месяц UTC или свой интервал с включённым началом и исключённым концом. Предпросмотр читает реальные данные без сохранения и использует ту же панель предупреждений, что приложения и панель мониторинга. Сохранение требует входа и действует только для вашей учётной записи; расчёты, история и рабочие состояния не изменяются. Предупреждения используют период каждого ограничения независимо от фильтров страницы. Настройки анализа заполняют только отсутствующие параметры URL панели мониторинга и страницы приложения. Частичные данные ниже порога не доказывают соблюдение ограничения; отсутствие данных никогда не означает ноль.
