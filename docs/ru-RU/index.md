# GreenER

GreenER объединяет непрерывный мониторинг, оценки энергии и CO₂e и экологический анализ в единой платформе. Динамический каталог, панель, история, рейтинг, сравнение и региональное моделирование связывают общий обзор с изучением отдельных приложений; показатели прослеживаются до исходных данных и методологии.

## С чего начать {#start}

Начните с экологической сводки, найдите приложение, требующее внимания, и откройте подробности. Изучите период в истории и основание оценки в методологии. Перед сравнением всегда учитывайте покрытие.

## Язык и оформление {#languages}

Выберите один из 12 языков; выбор остаётся в этом браузере. Тёмная тема меняет оформление, до явного выбора оно следует системе. Заблокированное хранилище может потерять настройки при перезагрузке. Язык меняет формат дат и чисел, сохраняя моменты наблюдений.

## Интегрированный продукт и инженерия {#engineering}

React 19 и TypeScript обеспечивают интерфейс; NestJS организует API в модули и слои с внедрением зависимостей; TypeORM и PostgreSQL сохраняют данные через версионируемые миграции. Проверяемые интеграции, транзакционный аудит и снимки расчётов поддерживают согласованность показателей.
