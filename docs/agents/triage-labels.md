# Labels de triagem

As skills de engenharia usam os seguintes labels no GitHub Issues:

| Papel canônico | Label no rastreador | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Issue precisa de avaliação do responsável. |
| `needs-info` | `needs-info` | Aguarda informações de quem reportou. |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pronta para execução por agente. |
| `ready-for-human` | `ready-for-human` | Requer implementação humana. |
| `wontfix` | `wontfix` | Não será executada. |
