# 사용 안내

기준: `origin/develop`, 커밋 `c343698`, 2026-11-08 확인. 환경마다 버전이 다를 수 있으며 병합이 배포를 증명하지 않습니다.

카탈로그/상세는 식별, 위치, 지표, 시간을 보존합니다. 이름/ID/지역 검색, 상태, 페이지는 URL에 유지합니다. 각 시도 종료 후 60초 폴링은 백엔드 수집과 독립입니다. 성공 후 실패하면 이전 데이터와 시간을 보존합니다. `AVAILABLE`, `UNAVAILABLE`, `NO_METRICS`, `REMOVED`는 사용량이 아니며 누락/오류/stale은 0이 아닙니다. 도시는 null일 수 있습니다. 연속 3회 유효 관측으로 복구하며 출처 오류로 제거를 확정하지 않습니다.



## Dashboard

`/dashboard`에서 24시간, 7·30·90일, 상태와 지역을 선택합니다. 합계, 커버리지, 상태별 개수와 배출량 구성의 막대/도넛 차트를 제공합니다. 표는 검색, 열 필터, 에너지/CO₂e 정렬과 페이지 이동을 지원하며 표 필터는 요약 합계를 변경하지 않습니다. 앱을 열어 근거를 조사합니다. `GET /analysis/summary`를 새로고침 없이 주기적으로 조회합니다.



## 사용 안내

`/history`에서 앱을 선택하면 `applicationId`, 기간, 집계 단위를 URL에 유지합니다. 저장된 시계열, 필터, 표시 시간대, 이벤트, 번호 페이지와 버킷 검사를 제공합니다. 기여 내역도 5·10·15·20개 또는 전체 페이지 이동을 지원합니다. 백엔드 버킷은 UTC이며 표시 시간대는 재집계하지 않습니다. 상세 중첩은 같은 앱의 직전 동일 길이 기간을 비교합니다.

`/administration/calculations`에서 앱과 날짜를 골라 원본/미리보기를 비교합니다. 종료일은 UTC 하루 전체를 포함하며 API는 `[from,to)`를 받습니다. 공개 작업으로 현재 모델과 과거 지역의 현재 계수를 사용하고 저장하지 않습니다. 한도는 30일, 관측 10,000개입니다. `original`, `preview`, `warnings`, `status` (`available`, `empty`, `partial`)를 반환합니다. 계수 실패 시 계산 가능한 에너지는 보존하고 CO₂e는 미제공합니다. 백분율은 같은 단위/커버리지와 양수 기준이 필요합니다.



## 방법론과 데이터

`/methodology`는 에너지, 배출량, 커버리지, 분석 탭과 예제/개인 설정을 제공합니다. 로그인한 모든 역할이 자신의 탭만 저장하며 낙관적 버전 충돌은 409입니다. 표시 임계값은 전역 설정·계산·외부 알림을 바꾸지 않습니다. 저장된 기간/집계 단위는 상세 URL에 값이 없을 때만 적용합니다. 기록된 방법론은 `/services/:id/methodology`와 선택한 `collectionId`로 조회합니다.



## Login

대시보드와 환경 조회는 공개입니다. `/login`은 이메일/비밀번호 또는 활성화된 Google을 사용합니다. Admin은 Google 이후에도 6자리 TOTP 설정/확인이 필요하며 Analyst/Visitor에 관리 권한은 부여하지 않습니다. 프런트엔드 세션은 메모리에만 있어 새로고침 시 다시 로그인합니다. 백엔드는 JWT, 세션, 현재 역할/계정 상태를 검사합니다. 인증 누락/무효는 401, 역할 부족은 403이며 새 경로는 기본 보호됩니다.



## Locale / Theme

언어는 `greener:locale`, 테마는 `greener-theme`에 저장하며 명시 선택 전 시스템을 따릅니다. 저장 차단 시 새로고침 후 유지되지 않을 수 있습니다. 지역별 형식은 관측 시각을 바꾸지 않습니다.
