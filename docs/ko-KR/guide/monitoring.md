# 사용 안내

환경 요약에서 관심 앱을 찾고 상세를 엽니다. 이력으로 기간을 조사하고 방법론으로 추정 근거를 확인합니다. 결과를 비교하기 전에 항상 커버리지를 고려하세요.

## 애플리케이션 찾기 {#catalog}

카탈로그에서 이름, 식별자, 지역을 검색하고 상태로 필터링합니다. 표의 페이지를 이동해 앱을 엽니다. 결과가 없으면 필터를 확인하세요. 페이지 주소에 검색과 페이지 선택이 남아 공유하거나 다시 조회할 수 있습니다.

## 대시보드 읽기 {#dashboard}

대시보드에서 24시간, 7·30·90일, 지역, 상태를 선택합니다. 에너지, 배출량, 커버리지, 상태별 개수를 확인합니다. 배출 비율은 막대나 도넛 차트로 표시됩니다. 표의 검색·필터·영향도 정렬은 행을 바꾸며 요약 합계는 선택한 범위를 유지합니다.

시계열에서 에너지와 CO₂e를 전환하거나 구간 표를 확인할 수 있습니다. 24시간 범위는 시간별로, 나머지는 일별로 묶습니다. 구간은 UTC를 따르며 지표와 같은 필터를 사용합니다. 누락된 구간에는 값을 표시하지 않습니다.

## 상세 조사하기 {#detail}

상세를 열어 식별, 위치, 상태, 업데이트 시각을 확인하고 같은 기간의 지표와 환경 결과를 살펴봅니다. 기록된 방법론은 계산에 사용한 모델·매개변수·탄소 계수를 표시하며 결과를 바꾸지 않습니다. 도시가 없더라도 나머지 위치 정보는 유용합니다.

등가 계수는 배출량을 계산한 에너지로 가중한 지역 계수의 요약입니다. 계산 설명은 이 에너지를 사용하므로 일부 기간의 계수가 누락되면 총에너지보다 작을 수 있습니다. 계수 상세 정보를 열어 지역별 값과 출처를 확인하세요.

## 이력 살펴보기 {#history}

이력에서 앱, 기간, 시간·일·월·연 단위 그룹을 선택합니다. 필터와 페이지로 구간을 찾고 구성을 열어 포함 관측과 제외 내역을 확인합니다. 시간대는 날짜 표시만 바꾸며 집계는 UTC입니다. 상세 중첩은 같은 앱의 직전 동일 길이 기간과 비교합니다.

## 재계산 미리보기와 비교하기 {#preview}

재계산 미리보기에서 앱과 날짜를 선택해 원본을 현재 모델 및 관측 지역의 현재 탄소 계수 추정과 비교합니다. 마지막 날은 UTC 하루 전체를 포함합니다. 최대 30일, 10,000개 관측을 허용합니다. 미리보기는 저장되지 않으며 이력을 바꾸지 않습니다. 백분율 차이는 단위·커버리지가 같고 원본이 양수일 때 표시합니다.

## 분석 개인화 {#preferences}

방법론에서 에너지, 배출량, 커버리지, 분석 탭을 살펴봅니다. 데모는 화면에 명시된 예제 데이터를 사용합니다. 로그인하면 표시 임계값과 초기 기간·그룹을 저장할 수 있습니다. 각자 자신의 설정만 바꾸며 계산과 전체 설정은 보존합니다. 저장 충돌 시 설정을 다시 읽은 뒤 재시도하세요. 분석 주소에서 이미 선택한 옵션이 저장된 설정보다 우선합니다.

## 로그인 {#access}

카탈로그, 대시보드, 환경 조회는 로그인 없이 사용할 수 있습니다. 설정 저장은 이메일·비밀번호 또는 활성화되어 초대로 연결된 Google 계정으로 로그인합니다. 관리자는 인증 앱의 6자리 코드도 확인합니다. 새로고침은 화면 세션을 종료하므로 다시 로그인해야 합니다. 관리 권한은 계정 역할에 따릅니다.

## 언어와 외관 {#appearance}

선택기에서 12개 언어를 고릅니다. 선택은 이 브라우저에 저장됩니다. 다크 모드는 외관을 바꾸며 명시적 선택 전에는 시스템을 따릅니다. 저장이 차단되면 새로고침 후 설정이 사라질 수 있습니다. 언어는 날짜·숫자 형식을 바꾸지만 관측 시각은 유지합니다.

## 데이터 해석 {#data}

0은 유효 관측이 그 값을 뒷받침한다는 뜻입니다. 공백은 사용 가능한 데이터가 없다는 뜻이며 소비 0이 아닙니다. 업데이트 실패 시 마지막 유효값과 원래 시간을 유지할 수 있습니다. 의사결정 전 갱신 시각과 커버리지를 확인하세요. 각 시도 후 60초에 화면이 다시 조회하지만 매번 새 측정을 보장하지는 않습니다.

| 상태 | 의미 |
| --- | --- |
| 사용 가능 | 앱이 사용 가능한 지표를 반환했습니다. |
| 사용 불가 | 현재 시도가 실패했으며 유효 이력은 있을 수 있습니다. |
| 지표 없음 | 앱은 알려져 있지만 이번 시도에 사용 가능한 지표가 없습니다. |
| 제거됨 | 원본 카탈로그에서 부재를 확인했으며 식별과 이력은 유지합니다. |

커버리지는 기간 중 유효 관측이 뒷받침하는 비율입니다. 에너지와 배출량은 별도로 계산하므로 배출 계산용 탄소 계수가 없어도 에너지 추정은 있을 수 있습니다. 호환되는 기간·단위·커버리지를 비교하세요. 낮은 커버리지는 부분 분석이며 소비 감소의 증거가 아닙니다.

## 진단 {#support}

문제 보고 시 앱, 기간, 필터, 시간대가 있는 시각과 작업을 알려주세요. 기대 결과와 실제 결과를 설명하세요. 자격 증명·개인정보 없는 스크린샷이 도움이 됩니다.
