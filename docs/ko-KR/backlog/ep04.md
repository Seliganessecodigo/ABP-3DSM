# EP04 — 환경 대시보드

[EP04](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4)

## 개요 {#purpose}

대시보드에서 기간, 지역, 상태를 선택하여 에너지, CO₂e, 수집 성공률 및 상태별 애플리케이션을 확인합니다. 성공률은 기록된 시도 중 유효한 지표를 받아 저장한 비율이며 기록이 없으면 표시할 수 없습니다. 기간 내 첫 기록도 표시됩니다. 시간적 커버리지는 분석과 표에 유지되며 부분 데이터 경고가 제공됩니다. 차트, 검색, 필터 및 페이지 이동은 선택한 조건을 유지합니다.

이력에서 앱, 기간, 시간·일·월·연 단위 그룹을 선택합니다. 필터와 페이지로 구간을 찾고 구성을 열어 포함 관측과 제외 내역을 확인합니다. 시간대는 날짜 표시만 바꾸며 집계는 UTC입니다. 상세 중첩은 같은 앱의 직전 동일 길이 기간과 비교합니다.

## 검증 기준 {#acceptance}

인터페이스는 지표를 기간, 단위, 데이터 범위, 방법론과 연결하고 필터 및 탐색 맥락을 유지합니다. 로딩, 빈 결과, 오류, 오래된 데이터 상태를 명시적으로 처리합니다. 키보드, 보이는 포커스, 색상 외의 텍스트, 모바일, 테마, 12개 언어가 사용자 경험을 구성합니다.

| 규칙 | 의미 |
| --- | --- |
| 이력 보존 | 설정 변경과 미리보기는 원본을 대체하지 않습니다. |
| 명확한 누락 | 실패·지표 누락·이전 데이터는 0과 구분합니다. |
| 공개 조회 | 지표 읽기는 공개이며 설정 저장과 계정 관리는 권한이 필요합니다. |
