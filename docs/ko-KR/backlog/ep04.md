# EP04 — 환경 대시보드

[EP04](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4)

## 개요 {#purpose}

대시보드에서 24시간, 7·30·90일, 지역, 상태를 선택합니다. 에너지, 배출량, 커버리지, 상태별 개수를 확인합니다. 배출 비율은 막대나 도넛 차트로 표시됩니다. 표의 검색·필터·영향도 정렬은 행을 바꾸며 요약 합계는 선택한 범위를 유지합니다.

이력에서 앱, 기간, 시간·일·월·연 단위 그룹을 선택합니다. 필터와 페이지로 구간을 찾고 구성을 열어 포함 관측과 제외 내역을 확인합니다. 시간대는 날짜 표시만 바꾸며 집계는 UTC입니다. 상세 중첩은 같은 앱의 직전 동일 길이 기간과 비교합니다.

재계산 미리보기에서 앱과 날짜를 선택해 원본을 현재 모델 및 관측 지역의 현재 탄소 계수 추정과 비교합니다. 마지막 날은 UTC 하루 전체를 포함합니다. 최대 30일, 10,000개 관측을 허용합니다. 미리보기는 저장되지 않으며 이력을 바꾸지 않습니다. 백분율 차이는 단위·커버리지가 같고 원본이 양수일 때 표시합니다.

## 검증 기준 {#acceptance}

제품은 앱을 찾고 0과 누락을 구분하며 지표의 기간·단위·커버리지·방법론을 추적할 수 있어야 합니다. 조회는 탐색 맥락을 유지하고 로딩·빈 결과·오류·이전 데이터를 알려야 합니다. 평가에는 키보드, 보이는 포커스, 색상 외 텍스트, 모바일과 12개 언어를 포함합니다.

| 규칙 | 의미 |
| --- | --- |
| 이력 보존 | 설정 변경과 미리보기는 원본을 대체하지 않습니다. |
| 명확한 누락 | 실패·지표 누락·이전 데이터는 0과 구분합니다. |
| 공개 조회 | 지표 읽기는 공개이며 설정 저장과 계정 관리는 권한이 필요합니다. |
