# EP05 — 분석과 시뮬레이션

[EP05](https://github.com/Seliganessecodigo/ABP-3DSM/issues/5)

## 개요 {#purpose}

커버리지는 기간 중 유효 관측이 뒷받침하는 비율입니다. 에너지와 배출량은 별도로 계산하므로 배출 계산용 탄소 계수가 없어도 에너지 추정은 있을 수 있습니다. 호환되는 기간·단위·커버리지를 비교하세요. 낮은 커버리지는 부분 분석이며 소비 감소의 증거가 아닙니다.

**환경 순위 · 애플리케이션 비교 · 지역 시뮬레이션**

## 검증 기준 {#acceptance}

앱 비교는 호환되는 기간·단위·커버리지를 사용해야 합니다. 지역 시뮬레이션은 관측 에너지를 유지하고 시나리오 탄소 계수를 바꾸며 공식 지표와 별도로 결과를 표시합니다.

인터페이스는 지표를 기간, 단위, 데이터 범위, 방법론과 연결하고 필터 및 탐색 맥락을 유지합니다. 로딩, 빈 결과, 오류, 오래된 데이터 상태를 명시적으로 처리합니다. 키보드, 보이는 포커스, 색상 외의 텍스트, 모바일, 테마, 12개 언어가 사용자 경험을 구성합니다.

| 규칙 | 의미 |
| --- | --- |
| 이력 보존 | 설정 변경과 미리보기는 원본을 대체하지 않습니다. |
| 명확한 누락 | 실패·지표 누락·이전 데이터는 0과 구분합니다. |
| 공개 조회 | 지표 읽기는 공개이며 설정 저장과 계정 관리는 권한이 필요합니다. |
