# EP06 — 설정과 관리

[EP06](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6)

## 개요 {#purpose}

선택기에서 12개 언어를 고릅니다. 선택은 이 브라우저에 저장됩니다. 다크 모드는 외관을 바꾸며 명시적 선택 전에는 시스템을 따릅니다. 저장이 차단되면 새로고침 후 설정이 사라질 수 있습니다. 언어는 날짜·숫자 형식을 바꾸지만 관측 시각은 유지합니다.

방법론에서 에너지, 배출량, 커버리지, 분석 탭을 살펴봅니다. 데모는 화면에 명시된 예제 데이터를 사용합니다. 로그인하면 표시 임계값과 초기 기간·그룹을 저장할 수 있습니다. 각자 자신의 설정만 바꾸며 계산과 전체 설정은 보존합니다. 저장 충돌 시 설정을 다시 읽은 뒤 재시도하세요. 분석 주소에서 이미 선택한 옵션이 저장된 설정보다 우선합니다.

카탈로그, 대시보드, 환경 조회는 로그인 없이 사용할 수 있습니다. 설정 저장은 이메일·비밀번호 또는 활성화되어 초대로 연결된 Google 계정으로 로그인합니다. 관리자는 인증 앱의 6자리 코드도 확인합니다. 새로고침은 화면 세션을 종료하므로 다시 로그인해야 합니다. 관리 권한은 계정 역할에 따릅니다.

## 검증 기준 {#acceptance}

제품은 앱을 찾고 0과 누락을 구분하며 지표의 기간·단위·커버리지·방법론을 추적할 수 있어야 합니다. 조회는 탐색 맥락을 유지하고 로딩·빈 결과·오류·이전 데이터를 알려야 합니다. 평가에는 키보드, 보이는 포커스, 색상 외 텍스트, 모바일과 12개 언어를 포함합니다.

| 규칙 | 의미 |
| --- | --- |
| 이력 보존 | 설정 변경과 미리보기는 원본을 대체하지 않습니다. |
| 명확한 누락 | 실패·지표 누락·이전 데이터는 0과 구분합니다. |
| 공개 조회 | 지표 읽기는 공개이며 설정 저장과 계정 관리는 권한이 필요합니다. |
