# 품질과 인수 기준

인터페이스는 지표를 기간, 단위, 데이터 범위, 방법론과 연결하고 필터 및 탐색 맥락을 유지합니다. 로딩, 빈 결과, 오류, 오래된 데이터 상태를 명시적으로 처리합니다. 키보드, 보이는 포커스, 색상 외의 텍스트, 모바일, 테마, 12개 언어가 사용자 경험을 구성합니다.

## 인수 기준 {#acceptance}

| 규칙 | 의미 |
| --- | --- |
| 이력 보존 | 설정 변경과 미리보기는 원본을 대체하지 않습니다. |
| 명확한 누락 | 실패·지표 누락·이전 데이터는 0과 구분합니다. |
| 공개 조회 | 지표 읽기는 공개이며 설정 저장과 계정 관리는 권한이 필요합니다. |

## 데이터 해석 {#integrity}

0은 유효 관측이 그 값을 뒷받침한다는 뜻입니다. 공백은 사용 가능한 데이터가 없다는 뜻이며 소비 0이 아닙니다. 업데이트 실패 시 마지막 유효값과 원래 시간을 유지할 수 있습니다. 의사결정 전 갱신 시각과 커버리지를 확인하세요. 각 시도 후 60초에 화면이 다시 조회하지만 매번 새 측정을 보장하지는 않습니다.

커버리지는 기간 중 유효 관측이 뒷받침하는 비율입니다. 에너지와 배출량은 별도로 계산하므로 배출 계산용 탄소 계수가 없어도 에너지 추정은 있을 수 있습니다. 호환되는 기간·단위·커버리지를 비교하세요. 낮은 커버리지는 부분 분석이며 소비 감소의 증거가 아닙니다.

## 검증 기준 {#assessment}

에픽, 스토리, 작업은 검증 가능한 기준과 코드 참조로 제품을 구성합니다. 이슈, 풀 리퀘스트, 커밋이 요구사항·구현·테스트를 연결하며 버전 관리 문서는 아키텍처, 계약, 운영, 근거를 모읍니다.

## 검증 {#engineering}

문서의 기준 버전에서 CI는 프론트엔드 테스트 542개, 백엔드 테스트 705개, 통합 흐름 3개와 lint, 타입 검사, 빌드, 마이그레이션, SonarQube Cloud 게이트를 통과했습니다. 사이트는 12개 언어의 콘텐츠, 계약, 링크 동등성을 자동 검증합니다.
