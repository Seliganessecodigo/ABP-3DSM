# 엔지니어링 원칙

에픽, 스토리, 작업은 검증 가능한 기준과 코드 참조로 제품을 구성합니다. 이슈, 풀 리퀘스트, 커밋이 요구사항·구현·테스트를 연결하며 버전 관리 문서는 아키텍처, 계약, 운영, 근거를 모읍니다.

## 제품 규칙 {#rules}

| 규칙 | 의미 |
| --- | --- |
| 이력 보존 | 설정 변경과 미리보기는 원본을 대체하지 않습니다. |
| 명확한 누락 | 실패·지표 누락·이전 데이터는 0과 구분합니다. |
| 공개 조회 | 지표 읽기는 공개이며 설정 저장과 계정 관리는 권한이 필요합니다. |

## 통합 기능 {#planned}

애플리케이션 비교, 환경 순위, 지역 시뮬레이션, 사용자·역할 관리, 비밀번호 복구, 모니터링 제어를 제공합니다. JWT 인증, Google SSO, TOTP 2단계 인증이 관리 흐름을 보호하며 환경 데이터 조회는 공개됩니다.

## 추정 모델 {#method}

단순화 모델은 관측 구간의 CPU·메모리·디스크·네트워크로 에너지를 추정합니다. 추정 전력을 시간에 따라 에너지로 변환하고 지역 탄소 집약도를 곱해 배출량을 구합니다. 계수는 학술 모델 값이며 실제 전력 측정이나 공식 지역 계수가 아닙니다. 결과는 원래 사용한 방법론과 계수를 보존합니다.

## 인수 기준 {#acceptance}

인터페이스는 지표를 기간, 단위, 데이터 범위, 방법론과 연결하고 필터 및 탐색 맥락을 유지합니다. 로딩, 빈 결과, 오류, 오래된 데이터 상태를 명시적으로 처리합니다. 키보드, 보이는 포커스, 색상 외의 텍스트, 모바일, 테마, 12개 언어가 사용자 경험을 구성합니다.
