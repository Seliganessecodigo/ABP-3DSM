# GreenER

GreenER는 애플리케이션을 모니터링하고 추정 에너지 소비와 이산화탄소 환산 배출량(CO₂e)을 이해하도록 돕습니다. 지표, 위치, 이력을 모아 디지털 서비스의 환경 영향을 분석합니다.

## 시작할 곳 {#start}

환경 요약에서 관심 앱을 찾고 상세를 엽니다. 이력으로 기간을 조사하고 방법론으로 추정 근거를 확인합니다. 결과를 비교하기 전에 항상 커버리지를 고려하세요.

## 대상 독자 {#readers}

| 대상 | 필요 |
| --- | --- |
| 인프라 관리 | 애플리케이션을 파악하고 환경 변화를 추적합니다. |
| 환경 및 운영 분석 | 기간의 소비, 배출량, 데이터 품질을 조사합니다. |
| 개발 및 평가 | 제품 동작을 확인하고 결과를 재현합니다. |

## 언어와 외관 {#languages}

선택기에서 12개 언어를 고릅니다. 선택은 이 브라우저에 저장됩니다. 다크 모드는 외관을 바꾸며 명시적 선택 전에는 시스템을 따릅니다. 저장이 차단되면 새로고침 후 설정이 사라질 수 있습니다. 언어는 날짜·숫자 형식을 바꾸지만 관측 시각은 유지합니다.
