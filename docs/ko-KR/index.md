# GreenER

GreenER는 지속적인 모니터링, 에너지·CO₂e 추정, 환경 분석을 통합한 플랫폼입니다. 동적 카탈로그, 대시보드, 이력, 순위, 비교, 지역 시뮬레이션은 전체 현황과 개별 애플리케이션 분석을 연결하며 지표를 원본 데이터와 방법론까지 추적할 수 있습니다.

## 시작할 곳 {#start}

환경 요약에서 관심 앱을 찾고 상세를 엽니다. 이력으로 기간을 조사하고 방법론으로 추정 근거를 확인합니다. 결과를 비교하기 전에 항상 커버리지를 고려하세요.

## 대상 독자 {#readers}

| 대상 | 필요 |
| --- | --- |
| 인프라 관리 | 애플리케이션을 파악하고 환경 변화를 추적합니다. |
| 환경 및 운영 분석 | 기간의 소비, 배출량, 데이터 품질을 조사합니다. |
| 개발 및 평가 | 제품 동작을 확인하고 결과를 재현합니다. |

## 언어와 외관 {#languages}

선택기에서 12개 언어를 고릅니다. 선택은 이 브라우저에 저장됩니다. 다크 모드는 외관을 바꾸며 명시적 선택 전에는 시스템을 따릅니다. 저장이 차단되면 새로고침 후 설정이 사라질 수 있습니다. 언어는 날짜·숫자 형식을 바꾸지만 관측 시각은 유지합니다.

## 통합 제품과 엔지니어링 {#engineering}

React 19와 TypeScript가 인터페이스를 지원하고 NestJS는 의존성 주입으로 API를 모듈과 계층으로 구성합니다. TypeORM과 PostgreSQL은 버전 관리 마이그레이션으로 데이터를 보존합니다. 검증된 통합, 트랜잭션 감사, 계산 스냅샷이 지표 일관성을 뒷받침합니다.
