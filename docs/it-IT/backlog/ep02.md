## Percorso e criteri di verifica

| Storia | Scenario e risultato atteso |
| --- | --- |
| US-02 | ID nuovo una volta; prima assenza snapshot completo valido conferma rimozione; ritorno conserva identità/storico senza riempire lacune. |
| US-03 | Stato, motivo, ora; distinguere disponibilità/freschezza/calcolabilità con testo/icone oltre colore. |
| US-04 | Aggiornare senza reload/perdita filtri/pagina/app; vecchia risposta non sostituisce nuovo contesto; polling separato da raccolta. |
| US-05 | Errore app/fonte non invalida altri successi; mantenere osservazione e recuperare con evidenza valida. |

Payload invalido, timeout/errori non confermano rimozione. 404 metriche ambiguo. Integrazione/persistenza necessarie; timeout/retry/concorrenza/ritardi richiedono approvazione.
