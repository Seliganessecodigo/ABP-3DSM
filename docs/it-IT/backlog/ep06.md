# EP06 — Configurazione e amministrazione

Comprende lingue, temi, autorizzazioni e amministrazione di monitoraggio e account.

[Apri nel backlog GitHub](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6)

## User story

| Issue | Capacità |
| --- | --- |
| [US-16 · Più lingue](https://github.com/Seliganessecodigo/ABP-3DSM/issues/208) | Cambiare la lingua dell’interfaccia mantenendo un’esperienza comprensibile. |
| [US-17 · Temi chiaro e scuro](https://github.com/Seliganessecodigo/ABP-3DSM/issues/209) | Usare in modo coerente tema chiaro, scuro o di sistema. |

| [US-20 · Account e recupero accesso](https://github.com/Seliganessecodigo/ABP-3DSM/issues/153) | Amministrare account e ruoli con un flusso separato per reimpostare la password. |

Le issue collegate sono la fonte di riferimento per criteri di accettazione, task, dipendenze e stato. Questa pagina descrive l’ambito del prodotto, non lo stato dell’implementazione.

## Percorso e criteri di verifica

| Storia | Scenario e risultato atteso |
| --- | --- |
| US-16 | Otto lingue con identità/contesto/formato coerenti, istanti invariati. |
| US-17 | Chiaro/scuro/sistema con focus, contrasto e stati leggibili. |
| US-18 | Lettura pubblica, modifiche solo con JWT/permessi verificati dal backend. |
| US-19 | Parametri/pausa/ripresa/esecuzione autorizzati, conservare versioni/storico. |
| US-20 | Conti/ruoli e recupero separato, risposta generica, token invalido/scaduto/usato. |

Lingua non è permesso. Matrice/bootstrap/sessione/password pendenti. Handoff con stati/mobile/tastiera. Configurazione non riscrive risultati passati.
