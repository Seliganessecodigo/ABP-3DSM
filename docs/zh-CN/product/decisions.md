# 决策与依赖

范围和使用规则变更应在相应故事记录问题、预期结果和验收标准。产品评审与可用性评估记录困难、反馈和改进。数据保留、备份恢复、运营目标和外部配额仍需决策。

## 产品规则 {#rules}

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |

## 当前状态与依赖项 {#planned}

比较、区域模拟、排名、用户与角色管理、密码恢复和监控控制均已实现。管理操作需要授权；SSO和邮件发送依赖环境配置。CSV导出以及保留、备份和恢复策略仍属于待确定的产品事项。

## 估算模型 {#method}

简化模型根据观测区间的CPU、内存、磁盘和网络估算能源，按持续时间将功率转换为能源。排放是能源乘以地区碳强度。系数属于学术模型，不是电力实测或官方地区因子。结果保留其原始方法和因子。

## 验收标准 {#acceptance}

产品应能查找应用、区分零与缺失，并追踪指标的期间、单位、覆盖率和方法。查询保持导航上下文并说明加载、空、故障和旧数据。评估包括键盘、可见焦点、颜色之外的文字、移动设备及12种语言。
