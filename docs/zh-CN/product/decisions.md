# 工程原则

Epic、用户故事和任务通过可验证的标准与代码引用组织产品。Issue、拉取请求和提交连接需求、实现与测试；版本化文档汇集架构、契约、运维和证据。

## 产品规则 {#rules}

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |

## 集成功能 {#planned}

平台提供应用比较、环境排名、区域模拟、用户与角色管理、密码找回和监控控制。JWT认证、Google SSO和TOTP双因素认证保护管理流程，环境数据查询保持公开。

## 估算模型 {#method}

简化模型根据观测区间的CPU、内存、磁盘和网络估算能源，按持续时间将功率转换为能源。排放是能源乘以地区碳强度。系数属于学术模型，不是电力实测或官方地区因子。结果保留其原始方法和因子。

## 验收标准 {#acceptance}

界面将指标与时间段、单位、覆盖率和计算方法关联，并保留筛选与导航上下文。加载、空结果、故障和陈旧数据均有明确处理。键盘操作、可见焦点、颜色之外的文字、移动设备、主题和12种语言构成完整的使用体验。
