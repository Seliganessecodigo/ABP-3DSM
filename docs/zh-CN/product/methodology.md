# 方法与数据

简化模型根据观测区间的CPU、内存、磁盘和网络估算能源，按持续时间将功率转换为能源。排放是能源乘以地区碳强度。系数属于学术模型，不是电力实测或官方地区因子。结果保留其原始方法和因子。

## 理解数据 {#vocabulary}

| 概念 | 含义 |
| --- | --- |
| 应用 | 目录中具有稳定身份的服务。 |
| 观测 | 与某个区间对应的一组指标。 |
| 能源 | 期间估算量，单位kWh。 |
| 碳强度 | 地区因子，单位gCO₂e/kWh。 |
| 排放 | 明确单位的CO₂当量。 |
| 覆盖率 | 期间内有有效证据支持的比例。 |

## 估算模型 {#model}

| 参数 | 数值 |
| --- | --- |
| CPU (100%) | 100 W |
| 内存 | 0.375 W/GB |
| 磁盘 | 0.01 W/GB |
| 网络 | 0.02 W/GB |

```text
P [W] = P_CPU + P_RAM + P_disk + P_network
E [kWh] = P [W] × Δt [h] / 1000
CO₂e [g] = E [kWh] × I [gCO₂e/kWh]
```

## 理解覆盖率 {#coverage}

覆盖率是期间内有有效观测支持的比例。能源和排放分别计算覆盖率：缺少碳因子时仍可能有能源估算。请比较期间、单位和覆盖率兼容的结果。低覆盖率表示分析不完整，不证明消耗下降。

零表示有有效观测支持该值。空缺表示没有可用数据，不是零消耗。更新失败时可能保留最后有效读数及其原始时间。用于决策前请核对更新时间和覆盖率。每次请求结束60秒后界面重新查询，但不保证每次都有新测量。

## 期间与历史 {#history}

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |

在重算预览选择应用和日期，将原始结果与当前模型及所观测地区当前碳因子的估算比较。结束日期包含完整UTC日。最多30天、10,000条观测。预览不保存且不改变历史。只有单位和覆盖率一致且原值为正时才显示百分比差异。
