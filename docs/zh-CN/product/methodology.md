# 方法与数据含义

证据必须保留其含义：缺失、错误及过时数据不等于零。能源由带版本参数的简化模型估算，并非真实电力测量；这些参数不是官方区域因子。CO₂e换算关系已在#49/#53实现。

## 术语及单位

| 概念 | 含义 |
| --- | --- |
| 应用 | 稳定身份，名称和位置可改变。 |
| 观测/采集 | 持久化指标，关联应用及时间区间。 |
| 周期 | 发现、协调和采集的执行，不是单次测量。 |
| 能源 | 期间累计量，单位kWh；不等于功率。 |
| 碳强度 | 来源提供的区域因子，gCO₂e/kWh。 |
| CO₂e | 有明确单位和因子的等效排放。 |
| 覆盖度 | 请求期间中由有效证据支持的部分，能源与CO₂e分别计算。 |
| Stale | 保留的较早有效观测，不表示本次成功。 |

聚合器契约规定CPU为%，内存、磁盘及网络为GB。这些不是kWh；转换需要有文档的模型、系数和假设。

## 时间及来源

指标来源不公布测量时间戳。GreenER记录接收时间，并推导`[receivedAt - collection_interval_seconds, receivedAt]`，并不证明源端实际测量时点。

最近尝试、最近有效观测和登记更新时间含义不同。因子查询时间也不能证明其官方有效期。快照保留接收值、内部身份、契约及查询时间；未公布的文献来源和有效期保持未知。

## 环境时间规则

查询使用带明确时区的ISO时间戳并规范化为UTC，区间为[from,to)。UTC小时/日/月/年桶只计算重叠部分，包括首尾部分桶。24h/7d/30d/90d为时长精确的滚动窗口，KPI与序列共用时间锚点。最多10,000点；超限请求直接拒绝，不截断或自动更改粒度。序列按重叠时长分摊已保存结果，不重算原始观测；冲突按collectedAt最新、再按ID字典序升序解决，胜出结果缺少指标时保留缺口，不回退。无额外舍入；覆盖度和原始快照分别保留。

## 能源与排放

已实现的量纲关系：

    CO₂e [g] = 能源 [kWh] × 碳强度 [gCO₂e/kWh]

仅作教学示例：2 kWh × 100 gCO₂e/kWh = 200 gCO₂e = 0.2 kgCO₂e。不是批准的因子或产品读数，也没有定义CPU、内存、磁盘和网络如何转换为能源。

缺少因子时，有效能源仍有效，但CO₂e可能无法计算。零值必须有有效证据。

## 历史与场景

| 结果 | 规则 |
| --- | --- |
| 原始结果 | 保留使用的观测、配置、方法和因子。 |
| 重算预览 | 使用明确标识的当前配置，不保存、不替换原始结果；权限、限制及因子策略待定。 |
| 区域模拟 | 能源不变，评估另一地区因子，与正式结果分开。 |

总量、排名和比较需要兼容期间与覆盖度。缺口不填零，百分比需要有效分母。已批准的时间语义见上文。持久化时，能源、克单位排放及因子保留8位小数；覆盖度作为0到1的比例保留4位。计算中间值不舍入，JSON快照保留原始表示。
