# EP06 — 配置与管理

[EP06](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6)

## 概览 {#purpose}

选择器提供12种语言，选择保留在当前浏览器。深色模式切换外观，明确选择前跟随系统。存储被禁可能使偏好在刷新后丢失。语言改变日期和数字格式，不改变观测时刻。

在方法页面查看能源、排放、覆盖率和分析默认设置。预览查询真实数据并标明缺失或错误，不修改历史或公式。登录后可保存个人阈值和初始选项。地址中明确指定的日期、筛选和分组优先于已保存的默认值。

目录、仪表板和环境查询无需登录。保存偏好可用邮箱密码，或已启用且通过邀请绑定的Google账户。管理员还需确认认证应用的六位代码。刷新会结束界面会话，必须重新登录。管理权限由账户角色决定。

## 验证标准 {#acceptance}

界面将指标与时间段、单位、覆盖率和计算方法关联，并保留筛选与导航上下文。加载、空结果、故障和陈旧数据均有明确处理。键盘操作、可见焦点、颜色之外的文字、移动设备、主题和12种语言构成完整的使用体验。

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |
