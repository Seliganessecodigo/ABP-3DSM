## 用户路径与验证标准

| 故事 | 场景及预期结果 |
| --- | --- |
| US-16 | 八种语言，保持身份/上下文/格式一致，不改变时点。 |
| US-17 | 明/暗/系统主题，保留焦点、对比和状态可读性。 |
| US-18 | 公开查询，管理修改须后端验证JWT与权限。 |
| US-19 | 已授权参数/暂停/恢复/执行，保持版本及历史。 |
| US-20 | 账户/角色与独立密码恢复，通用响应和无效/过期/已用token处理。 |

语言偏好不是权限。矩阵、bootstrap、会话及密码策略待决。设计交接覆盖状态、移动端、键盘，配置不改写过去结果。
