产品应能查找应用、区分零与缺失，并追踪指标的期间、单位、覆盖率和方法。查询保持导航上下文并说明加载、空、故障和旧数据。评估包括键盘、可见焦点、颜色之外的文字、移动设备及12种语言。

## 验证标准 {#acceptance}

产品应能查找应用、区分零与缺失，并追踪指标的期间、单位、覆盖率和方法。查询保持导航上下文并说明加载、空、故障和旧数据。评估包括键盘、可见焦点、颜色之外的文字、移动设备及12种语言。

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |
