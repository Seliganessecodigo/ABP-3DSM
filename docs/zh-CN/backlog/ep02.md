## 用户路径与验证标准

| 故事 | 场景及预期结果 |
| --- | --- |
| US-02 | 新ID仅登记一次；完整有效快照首次缺席确认移除；返回保留身份与历史，不补造缺口。 |
| US-03 | 展示状态、原因、时间，区分可用性/新鲜度/可计算性，文字图标不只颜色。 |
| US-04 | 无reload、无筛选/页码/应用丢失地更新，旧响应不覆盖新上下文；UI轮询与采集独立。 |
| US-05 | 应用/来源故障不否定其他成功，保留有效观测并依据证据恢复。 |

无效载荷、timeout和源错误不确认移除，指标404含义不明确。集成/持久化为前提；retry、并发、延迟等需要批准策略。
