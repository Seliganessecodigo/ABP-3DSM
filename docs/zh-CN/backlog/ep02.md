# EP02 — 应用监控

[EP02](https://github.com/Seliganessecodigo/ABP-3DSM/issues/2)

## 概览 {#purpose}

零表示有有效观测支持该值。空缺表示没有可用数据，不是零消耗。更新失败时可能保留最后有效读数及其原始时间。用于决策前请核对更新时间和覆盖率。每次请求结束60秒后界面重新查询，但不保证每次都有新测量。

| 状态 | 含义 |
| --- | --- |
| 可用 | 应用返回了可用指标。 |
| 不可用 | 当前尝试失败，可能仍有有效历史。 |
| 无指标 | 应用已知，但本次没有可用指标。 |
| 已移除 | 来源目录已确认其缺席，身份和历史保留。 |

## 验证标准 {#acceptance}

产品应能查找应用、区分零与缺失，并追踪指标的期间、单位、覆盖率和方法。查询保持导航上下文并说明加载、空、故障和旧数据。评估包括键盘、可见焦点、颜色之外的文字、移动设备及12种语言。

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |
