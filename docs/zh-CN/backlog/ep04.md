# EP04 — 环境仪表板

[EP04](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4)

## 概览 {#purpose}

在仪表板选择时间段、区域和状态，可查看能源、CO₂e、采集成功率及按状态分类的应用。成功率指已记录的尝试中，返回有效指标并保存成功的比例；没有记录时不可用。页面会显示时间段内的首条记录。时间覆盖率仍保留在分析和表格中，并提示数据不完整。图表、搜索、筛选和分页保留所选条件。

在历史中选择应用、期间和小时、日、月或年分组。通过筛选和分页定位区间，打开组成查看纳入的观测及排除项。时区只改变日期显示，分组仍为UTC。详情叠加比较同一应用上一段等长期间。

## 验证标准 {#acceptance}

界面将指标与时间段、单位、覆盖率和计算方法关联，并保留筛选与导航上下文。加载、空结果、故障和陈旧数据均有明确处理。键盘操作、可见焦点、颜色之外的文字、移动设备、主题和12种语言构成完整的使用体验。

| 规则 | 含义 |
| --- | --- |
| 保留历史 | 更改偏好或生成预览不会替换原始结果。 |
| 明确缺失 | 故障、缺少指标和旧数据与零保持区别。 |
| 公开查询 | 读取指标无需登录，保存偏好和管理账户需要授权。 |
