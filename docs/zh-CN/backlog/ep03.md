## 用户路径与验证标准

| 故事 | 场景及预期结果 |
| --- | --- |
| US-06 | 查看值/单位、区间、接收和当前状态，缺失/无效不作零。 |
| US-07 | 批准模型按区间/期间计算，显示kWh及覆盖度。 |
| US-08 | 排放关联使用的因子快照，缺因子保留能源并标记CO₂e不可计算。 |
| US-09 | 追溯公式、参数、版本、来源及限制。 |

模型为`simplified-energy`版本`1`：CPU 100%为100 W，内存0.375 W/GB，磁盘0.01 W/GB，网络0.02 W/GB。这是简化模型参数，不是电力实测或官方地区因子。功率为各项之和；能源 = W × 小时 / 1000；CO₂e[g] = kWh × gCO₂e/kWh。快照保存方法与因子；使用当前因子的预览不改写原始记录。
