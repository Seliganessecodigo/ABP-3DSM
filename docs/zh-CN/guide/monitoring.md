# 使用指南

从环境摘要开始，找到值得关注的应用并打开详情。通过历史调查期间，通过方法了解估算依据。比较结果前始终考虑覆盖率。

## 查找应用 {#catalog}

在目录中按名称、标识符或地区搜索，并按状态筛选。翻阅表格后打开应用查看数据。没有匹配时先检查筛选条件。页面地址保留搜索和页码，便于分享或继续查询。

## 查看仪表板 {#dashboard}

在仪表板选择24小时、7、30或90天、地区和状态，查看能源、排放、覆盖率及状态分布。图表用柱形或环形显示排放占比。表格支持搜索、筛选和按影响排序；表格筛选仅改变行，摘要总量仍按选定范围计算。

## 调查应用详情 {#detail}

打开详情核对身份、位置、状态和更新时间，并查看同一期间的指标及环境结果。记录的方法显示计算使用的模型、参数和碳因子，不改变结果。缺少城市时，其他位置信息仍可使用。

## 浏览历史 {#history}

在历史中选择应用、期间和小时、日、月或年分组。通过筛选和分页定位区间，打开组成查看纳入的观测及排除项。时区只改变日期显示，分组仍为UTC。详情叠加比较同一应用上一段等长期间。

## 比较重算预览 {#preview}

在重算预览选择应用和日期，将原始结果与当前模型及所观测地区当前碳因子的估算比较。结束日期包含完整UTC日。最多30天、10,000条观测。预览不保存且不改变历史。只有单位和覆盖率一致且原值为正时才显示百分比差异。

## 个性化分析 {#preferences}

在方法中浏览能源、排放、覆盖率和分析标签。演示使用屏幕上标明的示例数据。登录后可保存显示阈值及初始期间和分组。每人只修改自身偏好，计算和全局设置不变。保存冲突时先重新读取偏好再重试。分析地址中已选的选项优先于已保存偏好。

## 登录账户 {#access}

目录、仪表板和环境查询无需登录。保存偏好可用邮箱密码，或已启用且通过邀请绑定的Google账户。管理员还需确认认证应用的六位代码。刷新会结束界面会话，必须重新登录。管理权限由账户角色决定。

## 语言与外观 {#appearance}

选择器提供12种语言，选择保留在当前浏览器。深色模式切换外观，明确选择前跟随系统。存储被禁可能使偏好在刷新后丢失。语言改变日期和数字格式，不改变观测时刻。

## 理解数据 {#data}

零表示有有效观测支持该值。空缺表示没有可用数据，不是零消耗。更新失败时可能保留最后有效读数及其原始时间。用于决策前请核对更新时间和覆盖率。每次请求结束60秒后界面重新查询，但不保证每次都有新测量。

| 状态 | 含义 |
| --- | --- |
| 可用 | 应用返回了可用指标。 |
| 不可用 | 当前尝试失败，可能仍有有效历史。 |
| 无指标 | 应用已知，但本次没有可用指标。 |
| 已移除 | 来源目录已确认其缺席，身份和历史保留。 |

覆盖率是期间内有有效观测支持的比例。能源和排放分别计算覆盖率：缺少碳因子时仍可能有能源估算。请比较期间、单位和覆盖率兼容的结果。低覆盖率表示分析不完整，不证明消耗下降。

## 诊断 {#support}

报告问题时提供应用、期间、筛选、带时区的时间及操作，并说明预期和实际结果。不包含凭据或隐私的截图有助排查。
