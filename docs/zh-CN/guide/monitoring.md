# 使用目录并调查应用

本指南介绍目录、运行详情以及界面中已提供的按应用环境分析。聚合摘要已在API中提供，但仪表板、排名、比较和管理仍是[史诗任务](../roadmap)中的计划能力。

## 查找应用

1. 打开前端；本地使用请参考[开始使用](../getting-started)。
2. 按名称、ID、区域代码或区域搜索，并组合状态筛选。
3. 使用分页。先清除筛选，再判断无匹配是否意味着目录为空。
4. 打开详情确认ID和位置。城市为空是有效情况；不完整的旧位置应视为未知。

URL中的`q`、`state`和`page`保存查询上下文。保存链接可重现条件。当前筛选在前端对API返回的列表执行。

## 跟踪更新

目录和详情在打开时请求API，并在每次尝试结束60秒后安排下一次请求。界面轮询、后端采集与聚合器间隔彼此独立；刷新画面不保证出现新观测。

界面显示尝试时间和有效响应时间。成功后失败会保留旧数据，但旧数据不是新观测。目录手动刷新可重试而不重新载入页面。离开画面会取消待完成请求。

## 分析环境结果

在应用详情中选择 24 小时、7 天、30 天或 90 天的滚动时间窗，并选择小时、日、月或年的粒度。时间序列展示已持久化结果中的能耗和 CO₂e。叠加视图会将所选时间窗与紧邻的、时长相同的前一时间窗进行比较。这是单个应用的时间比较，不是排名或应用间比较。

使用表格筛选和排序来查找时间桶。查看时间桶可了解纳入的贡献以及带原因的排除项。表格支持分页；界面目前只加载贡献的第一页。缺失区间和排除项不代表零。没有可计算的证据时，结果仍不可用。

## 理解情况

如需追溯指标，请在应用详情中打开**查看完整方法说明**。也可以在导航中选择**方法说明**并选择应用。页面展示已记录的模型、公式、参数和假设，并在可用时显示碳因子详情。从详情页打开时使用所选采集；从导航打开时使用最近一次有效采集。此页面解释已保存的证据，不会重新计算结果。

| 情况 | 含义及操作 |
| --- | --- |
| 目录为空 | API没有返回应用；检查初始发现。 |
| 无匹配结果 | 调整筛选，其他应用仍可能存在。 |
| 首次加载失败 | 没有有效数据；重试并检查运维状态。 |
| 成功后失败 | 保留旧显示并查看其时间。 |
| 未找到应用 | 检查ID或链接，不同于已知但移除的应用。 |
| 应用已移除 | 身份和历史仍保留；有效快照已确认缺席。 |

## 状态、语言和问题反馈

`AVAILABLE`、`UNAVAILABLE`、`NO_METRICS`、`REMOVED`表示运行状态。新鲜度、原因和可计算性是独立信息。可用应用可能没有碳因子；不可用应用仍可能有有效历史。详情页显示运行状态、指标、环境结果、历史序列和按时间段查看的贡献明细。请阅读[API参考](../reference/api)和[方法说明](../product/methodology)，区分缺失、故障和零值。

语言选择器支持八种语言并在当前浏览器保存偏好。语言变化不会改变身份或观测时点。

报告应包含环境、应用ID、筛选、带时区的时间、操作和预期/实际结果。截图避免凭据及私有数据。环境故障参考[运维](../operations)。

## 主题偏好

在导航偏好设置中使用 **深色模式** 开关：关闭为浅色，开启为深色。首次访问时，GreenER 会跟随系统外观及其变化，直到您操作开关。此后，以您的明确选择为准；此界面不提供恢复跟随系统的操作。

此选择适用于目录、详情和全局布局，不会更改筛选条件或数据。偏好通过 `greener-theme` 保存在此浏览器中，供下次访问使用。如果存储被阻止，选择在当前会话中仍然有效，但重新加载后可能丢失。
