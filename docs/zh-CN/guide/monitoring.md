# 使用指南

从环境摘要开始，找到值得关注的应用并打开详情。通过历史调查期间，通过方法了解估算依据。比较结果前始终考虑覆盖率。

## 查找应用 {#catalog}

在目录中按名称、标识符或地区搜索，并按状态筛选。翻阅表格后打开应用查看数据。没有匹配时先检查筛选条件。页面地址保留搜索和页码，便于分享或继续查询。

## 查看仪表板 {#dashboard}

在仪表板选择时间段、区域和状态，可查看能源、CO₂e、采集成功率及按状态分类的应用。成功率指已记录的尝试中，返回有效指标并保存成功的比例；没有记录时不可用。页面会显示时间段内的首条记录。时间覆盖率仍保留在分析和表格中，并提示数据不完整。图表、搜索、筛选和分页保留所选条件。

在时间序列中可切换能耗与CO₂e，或查看时段表格。24小时范围按小时分组，其他范围按天分组。时段采用UTC，并与指标使用相同筛选条件。缺失时段不显示数值。

## 调查应用详情 {#detail}

打开详情核对身份、位置、状态和更新时间，并查看同一期间的指标及环境结果。记录的方法显示计算使用的模型、参数和碳因子，不改变结果。缺少城市时，其他位置信息仍可使用。

等效因子按已计算排放量的能耗加权，汇总所使用的区域因子。计算说明使用这部分能耗，因此部分时段缺少因子时，该能耗可能小于总能耗。在计算方法中可查看各区域的数值与来源。因子卡片与其他指标保持相同高度，不在卡片内部展开。

## 浏览历史 {#history}

在历史中选择应用、期间和小时、日、月或年分组。通过筛选和分页定位区间，打开组成查看纳入的观测及排除项。时区只改变日期显示，分组仍为UTC。详情叠加比较同一应用上一段等长期间。

## 计算预览 {#preview}

应用比较须使用兼容的期间、单位和覆盖率。地区模拟保持观测能源、改变情景碳因子，并与正式指标分开展示结果。

## 个性化分析 {#preferences}

在方法页面查看能源、排放、覆盖率和分析默认设置。预览查询真实数据并标明缺失或错误，不修改历史或公式。登录后可保存个人阈值和初始选项。地址中明确指定的日期、筛选和分组优先于已保存的默认值。

## 登录账户 {#access}

目录、仪表板和环境查询无需登录。保存偏好可用邮箱密码，或已启用且通过邀请绑定的Google账户。管理员还需确认认证应用的六位代码。刷新会结束界面会话，必须重新登录。管理权限由账户角色决定。

## 语言与外观 {#appearance}

选择器提供12种语言，选择保留在当前浏览器。深色模式切换外观，明确选择前跟随系统。存储被禁可能使偏好在刷新后丢失。语言改变日期和数字格式，不改变观测时刻。

## 理解数据 {#data}

零表示有有效观测支持该值。空缺表示没有可用数据，不是零消耗。更新失败时可能保留最后有效读数及其原始时间。用于决策前请核对更新时间和覆盖率。每次请求结束60秒后界面重新查询，但不保证每次都有新测量。

| 状态 | 含义 |
| --- | --- |
| 可用 | 应用返回了可用指标。 |
| 不可用 | 当前尝试失败，可能仍有有效历史。 |
| 无指标 | 应用已知，但本次没有可用指标。 |
| 已移除 | 来源目录已确认其缺席，身份和历史保留。 |

覆盖率是期间内有有效观测支持的比例。能源和排放分别计算覆盖率：缺少碳因子时仍可能有能源估算。请比较期间、单位和覆盖率兼容的结果。低覆盖率表示分析不完整，不证明消耗下降。

## 诊断 {#support}

报告问题时提供应用、期间、筛选、带时区的时间及操作，并说明预期和实际结果。不包含凭据或隐私的截图有助排查。

## 其他分析和设置 {#other}

排名按所选时间段的能源或CO₂e排序。比较功能包含多个应用和一个参照应用；区域模拟保持能源不变并显示独立场景。授权用户可在设置中访问监控、账户和变更审计。个人账户允许修改密码；登录页面提供临时令牌恢复。
