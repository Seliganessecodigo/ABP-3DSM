# GreenER

GreenER帮助监控应用，理解其估算能源消耗及二氧化碳当量排放（CO₂e）。它汇集指标、位置和历史，支持分析数字服务的环境影响。

## 从哪里开始 {#start}

从环境摘要开始，找到值得关注的应用并打开详情。通过历史调查期间，通过方法了解估算依据。比较结果前始终考虑覆盖率。

## 适用人群 {#readers}

| 人群 | 需求 |
| --- | --- |
| 基础设施管理 | 识别应用并跟踪环境变化。 |
| 环境与运营分析 | 调查期间内的消耗、排放和数据质量。 |
| 开发与评估 | 验证产品行为并复现结果。 |

## 语言与外观 {#languages}

选择器提供12种语言，选择保留在当前浏览器。深色模式切换外观，明确选择前跟随系统。存储被禁可能使偏好在刷新后丢失。语言改变日期和数字格式，不改变观测时刻。
