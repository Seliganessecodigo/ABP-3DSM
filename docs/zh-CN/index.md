# GreenER

GreenER将持续监控、能源与CO₂e估算和环境分析整合到同一平台。动态目录、仪表盘、历史记录、排名、比较和区域模拟连接整体视图与单个应用的深入分析，指标可追溯至源数据和计算方法。

## 从哪里开始 {#start}

从环境摘要开始，找到值得关注的应用并打开详情。通过历史调查期间，通过方法了解估算依据。比较结果前始终考虑覆盖率。

## 适用人群 {#readers}

| 人群 | 需求 |
| --- | --- |
| 基础设施管理 | 识别应用并跟踪环境变化。 |
| 环境与运营分析 | 调查期间内的消耗、排放和数据质量。 |
| 开发与评估 | 验证产品行为并复现结果。 |

## 语言与外观 {#languages}

选择器提供12种语言，选择保留在当前浏览器。深色模式切换外观，明确选择前跟随系统。存储被禁可能使偏好在刷新后丢失。语言改变日期和数字格式，不改变观测时刻。

## 集成产品与工程 {#engineering}

React 19与TypeScript支撑界面，NestJS通过依赖注入将API组织为模块与分层，TypeORM和PostgreSQL通过版本化迁移保存数据。经过验证的集成、事务审计和计算快照共同支撑指标一致性。
