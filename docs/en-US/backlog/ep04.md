# EP04 — Environmental dashboard

Aggregates indicators and supports detail and history investigation.

[Open in GitHub backlog](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4)

## User stories

| Issue | Capability |
| --- | --- |
| [US-10 · Environmental summary](https://github.com/Seliganessecodigo/ABP-3DSM/issues/16) | View aggregate totals and indicators for the selected period. |
| [US-11 · Application detail](https://github.com/Seliganessecodigo/ABP-3DSM/issues/17) | Investigate an application’s state, location, metrics, and environmental results. |
| [US-12 · Environmental history](https://github.com/Seliganessecodigo/ABP-3DSM/issues/18) | Explore historical series; recalculation preview uses current configuration and does not save or change original history. |

Linked issues are the source of truth for acceptance criteria, task breakdown, dependencies, and status. This page describes product scope, not implementation status.
