# EP06 — Configuration and administration

Covers languages, themes, authorization, and monitoring and account administration.

[Open in GitHub backlog](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6)

## User stories

| Issue | Capability |
| --- | --- |
| [US-16 · Multiple languages](https://github.com/Seliganessecodigo/ABP-3DSM/issues/208) | Switch interface language while keeping supported experiences understandable. |
| [US-17 · Light and dark themes](https://github.com/Seliganessecodigo/ABP-3DSM/issues/209) | Use light, dark, or system theme consistently. |
| [US-18 · Configuration access](https://github.com/Seliganessecodigo/ABP-3DSM/issues/23) | Protect administrative operations through backend authentication and authorization. |
| [US-19 · Monitoring and parameters](https://github.com/Seliganessecodigo/ABP-3DSM/issues/24) | Configure authorized intervals and parameters while preserving versions and history. |
| [US-20 · Accounts and access recovery](https://github.com/Seliganessecodigo/ABP-3DSM/issues/153) | Administer accounts and roles, with a separate password reset flow. |

Linked issues are the source of truth for acceptance criteria, task breakdown, dependencies, and status. This page describes product scope, not implementation status.

## Journey and validation criteria

| Story | Scenario and expected result |
| --- | --- |
| US-16 | Switch eight languages, preserving identity/context and coherent formatting without changing instants. |
| US-17 | Choose light, dark or system while preserving focus, contrast and readable states. |
| US-18 | Allow public reads and reject administrative changes without backend-verified JWT/permission. |
| US-19 | Configure parameters and pause/resume/trigger monitoring under authorization; preserve versions/history. |
| US-20 | Manage accounts/roles and recover passwords in a separate flow with generic responses and invalid/expired/used-token handling. |

Language preference is not a permission profile. Access matrix, bootstrap, sessions and password policy still need decisions. Figma handoff must cover states, mobile and keyboard. Configuration must not rewrite previous results.
