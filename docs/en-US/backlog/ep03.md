# EP03 — Environmental impact calculation

Presents calculations with traceable evidence, units, methodology, and limitations.

[Open in GitHub backlog](https://github.com/Seliganessecodigo/ABP-3DSM/issues/3)

## User stories

| Issue | Capability |
| --- | --- |
| [US-06 · Metric evidence](https://github.com/Seliganessecodigo/ABP-3DSM/issues/12) | Inspect source metrics, interval, unit, and update time behind results. |
| [US-07 · Energy per application](https://github.com/Seliganessecodigo/ABP-3DSM/issues/13) | Estimate energy by application and period with explicit units and coverage. |
| [US-08 · CO₂e per application](https://github.com/Seliganessecodigo/ABP-3DSM/issues/14) | Estimate equivalent emissions with traceable factors and versions. |
| [US-09 · Methodology and limitations](https://github.com/Seliganessecodigo/ABP-3DSM/issues/15) | Explain formulas, sources, assumptions, and calculation limitations. |

Linked issues are the source of truth for acceptance criteria, task breakdown, dependencies, and status. This page describes product scope, not implementation status.
