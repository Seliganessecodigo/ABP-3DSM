# EP05 — Analysis and simulation

Helps prioritize and compare applications and preview a regional scenario without changing official results.

[Open in GitHub backlog](https://github.com/Seliganessecodigo/ABP-3DSM/issues/5)

## User stories

| Issue | Capability |
| --- | --- |
| [US-13 · Sort by impact](https://github.com/Seliganessecodigo/ABP-3DSM/issues/19) | Sort applications by energy and CO₂e over the same time range. |
| [US-14 · Compare applications](https://github.com/Seliganessecodigo/ABP-3DSM/issues/20) | Compare at least two applications with compatible periods, units, and coverage. |
| [US-15 · Regional simulation](https://github.com/Seliganessecodigo/ABP-3DSM/issues/22) | Preview the effect of another regional factor while keeping observed energy unchanged. |

Linked issues are the source of truth for acceptance criteria, task breakdown, dependencies, and status. This page describes product scope, not implementation status.

## Journey and validation criteria

| Story | Scenario and expected result |
| --- | --- |
| US-13 | Rank energy/CO₂e for the same period, identifying unrankable items without treating them as zero. |
| US-14 | Compare at least two applications with compatible units, periods and coverage; state incompatibility instead of suggesting false precision. |
| US-15 | Select a different regional factor while keeping scenario energy constant; distinguish simulation from official results. |

Still outside delivery: dedicated comparison of at least two applications, regional simulation, general user/role management, self-service password recovery, global monitoring configuration/pause and CSV export. Dashboard sorting by impact is available. External quotas, retention, backup/restore and operational targets need decisions; no SLA is declared. TOTP recovery is a support operation, not a password reset.
