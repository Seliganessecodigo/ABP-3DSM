| Issue | Capability |
| --- | --- |

## Journey and validation criteria

| Story | Scenario and expected result |
| --- | --- |
| US-02 | Insert a new ID once. First absence in a complete valid snapshot confirms removal. Return reuses identity/history without backfilling the gap. |
| US-03 | Present state with reason/time; distinguish availability, freshness and calculability using text/icons beyond color. |
| US-04 | Refresh without reload or lost filters/page/application; an old response never replaces new context. UI polling is separate from collection. |
| US-05 | An application/source failure does not invalidate other successes. Preserve the last valid observation and recover from valid evidence. |

Invalid payloads, timeout and source errors do not confirm removal. Metrics 404 is ambiguous. Integration/persistence are prerequisites; timeout/retry/concurrency and delay limits need an approved policy.
