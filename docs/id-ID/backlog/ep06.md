[EP06](https://github.com/Seliganessecodigo/ABP-3DSM/issues/6)

## Ringkasan {#purpose}

Pilih salah satu dari 12 bahasa; pilihan tersimpan di browser ini. Mode gelap mengubah tampilan, mengikuti sistem sebelum pilihan eksplisit. Penyimpanan diblokir dapat menghilangkan preferensi saat reload. Bahasa mengubah format tanggal/angka tanpa mengubah waktu observasi.

Di Metodologi, jelajahi energi, emisi, cakupan dan bawaan analisis. Pratinjau menggunakan data nyata dan menandai ketiadaan atau kegagalan; riwayat dan rumus tidak diubah. Masuk untuk menyimpan ambang pribadi dan opsi awal. Tanggal, filter dan pengelompokan eksplisit pada alamat mengesampingkan bawaan tersimpan.

Katalog, dashboard dan kueri lingkungan dapat diakses tanpa masuk. Untuk menyimpan preferensi gunakan email/kata sandi atau Google yang diaktifkan dengan akun tertaut melalui undangan. Admin juga mengonfirmasi kode enam digit dari aplikasi autentikator. Memuat ulang halaman mengakhiri sesi antarmuka sehingga perlu masuk lagi. Izin administrasi mengikuti peran akun.

## Kriteria validasi {#acceptance}

Antarmuka menghubungkan indikator dengan periode, satuan, cakupan dan metodologi sambil mempertahankan filter serta konteks navigasi. Status pemuatan, kosong, kegagalan dan data usang ditangani secara eksplisit. Keyboard, fokus terlihat, teks selain warna, perangkat seluler, tema dan 12 bahasa merupakan bagian dari pengalaman pengguna.

| Aturan | Makna |
| --- | --- |
| Riwayat terjaga | Preferensi dan pratinjau tidak mengganti hasil asli. |
| Ketiadaan eksplisit | Kegagalan, metrik hilang dan data lama dibedakan dari nol. |
| Kueri publik | Membaca indikator tidak perlu masuk; menyimpan preferensi dan mengelola akun memerlukan izin. |
