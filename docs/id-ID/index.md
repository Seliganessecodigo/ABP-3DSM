# GreenER

GreenER menyatukan pemantauan berkelanjutan, estimasi energi dan CO₂e, serta analisis lingkungan dalam platform terintegrasi. Katalog dinamis, dasbor, riwayat, peringkat, perbandingan dan simulasi regional menghubungkan gambaran umum dengan penyelidikan setiap aplikasi; indikator dapat ditelusuri ke data dan metodologi asalnya.

## Mulai dari sini {#start}

Mulai dari ringkasan lingkungan, cari aplikasi yang perlu perhatian dan buka detailnya. Gunakan riwayat untuk menelusuri periode dan metodologi untuk memahami estimasi. Pertimbangkan cakupan sebelum membandingkan hasil.

## Untuk siapa {#readers}

| Pengguna | Kebutuhan |
| --- | --- |

| Pengembangan dan evaluasi | Memeriksa perilaku produk dan mereproduksi hasil. |

## Bahasa dan tampilan {#languages}

Pilih salah satu dari 12 bahasa; pilihan tersimpan di browser ini. Mode gelap mengubah tampilan, mengikuti sistem sebelum pilihan eksplisit. Penyimpanan diblokir dapat menghilangkan preferensi saat reload. Bahasa mengubah format tanggal/angka tanpa mengubah waktu observasi.

## Produk terintegrasi dan rekayasa {#engineering}

React 19 dan TypeScript mendukung antarmuka; NestJS mengatur API dalam modul dan lapisan dengan injeksi dependensi; TypeORM dan PostgreSQL mempertahankan data melalui migrasi berversi. Integrasi tervalidasi, audit transaksional dan snapshot perhitungan mendukung konsistensi indikator.
