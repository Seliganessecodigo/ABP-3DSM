## 利用フローと検証基準

| ストーリー | シナリオと期待結果 |
| --- | --- |
| US-13 | 同期間のエネルギー・CO₂eで順位付け。分類不可はゼロにしない。 |
| US-14 | 最低2アプリを互換単位・期間・カバレッジで比較し、不整合を説明。 |
| US-15 | エネルギーを固定して別地域係数を選び、公式結果と区別。 |

未提供：複数アプリの専用比較、地域シミュレーション、一般ユーザー/役割管理、パスワード自己復旧、監視全体設定/一時停止、CSV。影響度順の並び替えは提供済み。外部割当量、保存期間、バックアップ/復元、運用目標は要決定。SLAは宣言しません。サポートのTOTP復旧はパスワードリセットではありません。
