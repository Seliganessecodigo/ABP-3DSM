# EP05 — 分析とシミュレーション

[EP05](https://github.com/Seliganessecodigo/ABP-3DSM/issues/5)

## 概要 {#purpose}

カバー率は有効な観測で裏付けられる期間の割合です。エネルギーと排出量は別々に計算され、炭素係数がなくてもエネルギー推定が得られる場合があります。期間、単位、カバー率が対応した結果を比較してください。低いカバー率は部分的な分析を示し、消費減少の証明にはなりません。

**環境ランキング · アプリケーション比較 · 地域シミュレーション**

## 検証基準 {#acceptance}

アプリ比較は期間、単位、カバー率を対応させます。地域シミュレーションは観測エネルギーを保持し、シナリオの炭素係数を変更して公式指標と別に結果を表示します。

画面は指標を期間、単位、カバレッジ、方法論に結び付け、フィルターとナビゲーションの文脈を保持します。読み込み、空、障害、古いデータの状態を明示し、キーボード、見えるフォーカス、色に加えたテキスト、モバイル、テーマ、12言語に対応しています。

| ルール | 意味 |
| --- | --- |
| 履歴の保持 | 設定変更やプレビューで原本を置き換えません。 |
| 欠損の明示 | 失敗、メトリクス不足、古いデータはゼロと区別します。 |
| 公開参照 | 指標の参照は公開です。設定保存とアカウント管理には権限が必要です。 |
