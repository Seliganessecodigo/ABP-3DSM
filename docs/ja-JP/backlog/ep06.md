## 利用フローと検証基準

| ストーリー | シナリオと期待結果 |
| --- | --- |
| US-16 | 8言語でID・条件・書式を維持、時点を変えない。 |
| US-17 | 明・暗・systemでfocus・contrast・状態の可読性を保持。 |
| US-18 | 公開参照を許可し、管理変更はbackendのJWT・権限確認で保護。 |
| US-19 | 認可された設定・停止・再開・実行、版と履歴を保全。 |
| US-20 | アカウント・role管理と別のpassword復旧、汎用応答、不正・期限切れ・使用済みtokenを処理。 |

言語設定は権限ではありません。matrix・bootstrap・session・passwordは未決。引継ぎは状態・mobile・keyboardを含めます。設定で過去を変更しません。
