# EP01 — アプリケーション一覧

GreenERが監視するアプリケーションを探して閲覧できます。

[GitHubバックログで開く](https://github.com/Seliganessecodigo/ABP-3DSM/issues/1)

## ユーザーストーリー

| Issue | 機能 |
| --- | --- |
| [US-01 · 監視対象アプリケーション一覧](https://github.com/Seliganessecodigo/ABP-3DSM/issues/7) | 認識済みアプリケーションの識別情報と状態を一覧・検索する。 |

受け入れ条件、タスク分解、依存関係、状態の正本はリンク先のissueです。このページは製品の範囲を説明し、実装状況を示すものではありません。

[GitHubバックログで開く](https://github.com/orgs/Seliganessecodigo/projects/2/views/1)
[Figma](https://www.figma.com/design/bbt97My6jOZpJVYxbOc9T2/Untitled?node-id=0-1)

## 利用フローと検証基準

| ストーリー | シナリオと期待結果 |
| --- | --- |
| US-01 | 一覧を開き検索・絞り込み後、同じIDの詳細へ。アプリなしは空、API・元の障害はエラー、検索一致なしでは一覧自体を消さない。 |

都市nullは許可、地域コード・国・地域・座標は元の契約で必須です。不完全な旧データも所在地を捏造せず保持します。

一覧はEP02の状態とEP03の証拠を利用し、参照時に収集・計算しません。[利用ガイド](../guide/monitoring)を参照。
