# EP04 — 環境ダッシュボード

[EP04](https://github.com/Seliganessecodigo/ABP-3DSM/issues/4)

## 概要 {#purpose}

ダッシュボードで24時間、7・30・90日、地域、状態を選びます。エネルギー、排出量、カバー率、状態別件数を確認できます。排出割合は棒またはドーナツ図で表示します。表の検索・フィルター・影響順の並べ替えは行だけを変更し、合計は選択した集計範囲を維持します。

履歴でアプリ、期間、時・日・月・年の集計単位を選びます。フィルターとページ切替で区間を探し、内訳を開いて含まれた観測と除外を調べます。タイムゾーンは日付表示だけを変更し、集計はUTCのままです。詳細の重ね合わせは同じアプリの直前の同じ長さの期間と比較します。

再計算プレビューでアプリと日付を選び、原本を現行モデルと観測地域の現在の炭素係数による推定と比較します。終了日はUTCの一日全体を含みます。上限は30日、10,000観測です。プレビューは保存されず履歴を変更しません。割合の差は単位とカバー率が一致し、原本が正の値の場合に表示します。

## 検証基準 {#acceptance}

アプリを見つけ、ゼロと欠損を区別し、指標から期間、単位、カバー率、方法論まで追跡できることが必要です。参照では移動時の条件を保持し、読み込み、空、失敗、古いデータを伝えます。評価にはキーボード、可視フォーカス、色以外の文字情報、モバイル、12言語を含めます。

| ルール | 意味 |
| --- | --- |
| 履歴の保持 | 設定変更やプレビューで原本を置き換えません。 |
| 欠損の明示 | 失敗、メトリクス不足、古いデータはゼロと区別します。 |
| 公開参照 | 指標の参照は公開です。設定保存とアカウント管理には権限が必要です。 |
