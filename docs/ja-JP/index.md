# GreenER

GreenERは継続監視、エネルギー・CO₂e推計、環境分析を統合したプラットフォームです。動的カタログ、ダッシュボード、履歴、ランキング、比較、地域シミュレーションが全体像と個別アプリケーションの調査を結び、指標から元データと方法論を追跡できます。

## 最初に読むページ {#start}

環境サマリーから注目するアプリを選び、詳細を開きます。履歴で期間を調べ、方法論で推定の根拠を確認します。比較する前に必ずカバー率を考慮してください。

## 対象読者 {#readers}

| 対象 | 必要性 |
| --- | --- |
| インフラ管理 | アプリを把握し、環境の変化を追跡する。 |
| 環境・運用分析 | 対象期間の消費、排出、データ品質を調べる。 |
| 開発・評価 | 製品の動作を確認し、結果を再現する。 |

## 言語と表示 {#languages}

セレクターから12言語を選べます。選択はこのブラウザーに保存されます。ダークモードで外観を変更でき、明示的に選ぶまではシステムに従います。保存が禁止されていると再読み込み後に失われる場合があります。言語によって日付と数値の書式が変わりますが、観測時刻そのものは変わりません。

## 統合製品とエンジニアリング {#engineering}

React 19とTypeScriptが画面を支え、NestJSは依存性注入を用いてAPIをモジュールとレイヤーに分離します。TypeORMとPostgreSQLはバージョン付きマイグレーションでデータを保持し、検証済み連携、トランザクション監査、計算スナップショットが指標の一貫性を支えます。
