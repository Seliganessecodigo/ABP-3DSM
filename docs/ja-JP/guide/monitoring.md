# 一覧を使ってアプリケーションを調べる

一覧、運用詳細、UIで利用できるアプリ別環境分析のガイドです。集計サマリーはAPIにありますが、ダッシュボード、ランキング、比較、管理は[エピック](../roadmap)の計画機能です。

## アプリケーションを探す

1. フロントエンドを開きます。ローカルでは[はじめに](../getting-started)を参照します。
2. 名前、ID、地域コード、地域名で検索し、状態フィルターを組み合わせます。
3. ページを切り替えます。検索結果ゼロを空の一覧と判断する前にフィルターを解除します。
4. 詳細でIDと所在地を確認します。都市のnullは有効です。不完全な旧所在地は不明として扱います。

URLの`q`、`state`、`page`が条件を保持します。リンクを保存すると条件を再現できます。現在のフィルターはAPIの一覧に対してフロントエンドで適用されます。

## 更新を追う

一覧と詳細は表示時にAPIを呼び、各試行終了から60秒後に次の要求を予定します。UIのポーリング、バックエンド収集、集約元の間隔は別々です。画面更新が新しい観測を保証するわけではありません。

UIは試行時刻と有効な応答時刻を表示します。成功後の失敗では以前のデータを保持しますが、新しい観測にはなりません。一覧の手動更新ではリロードせずに再試行できます。画面を離れると未完了の要求はキャンセルされます。

## 環境結果を分析する

アプリ詳細で、24時間、7日、30日、90日のローリング期間と、時間、日、月、年の粒度を選択します。時系列は保存済みの結果に基づくエネルギーとCO₂eを示します。重ね合わせ表示では、選択期間と同じ長さの直前期間を比較します。これは1つのアプリの期間比較であり、ランキングやアプリ間比較ではありません。

表のフィルターと並べ替えでバケットを探します。バケットを調べると、含まれる寄与と理由付きの除外を確認できます。表はページ分割され、現在UIが読み込む寄与は最初のページのみです。欠損や除外はゼロを意味しません。計算可能な証拠がない場合、結果は利用不可のままです。

## 状況を読む

指標の根拠を確認するには、アプリ詳細の**方法論全体を見る**を開きます。ナビゲーションの**方法論**からアプリを選ぶこともできます。この画面では記録されたモデル、式、パラメーター、前提条件と、利用可能な場合は炭素係数の詳細を表示します。詳細画面から開くと選択中の収集データを使い、ナビゲーションから開くと最新の有効な収集データを使います。保存済みの証拠を説明する画面であり、結果は再計算しません。

| 状況 | 意味・対応 |
| --- | --- |
| 一覧が空 | APIがアプリを返していない。初期検出を確認する。 |
| フィルターに一致しない | 条件を変更する。他のアプリは存在し得る。 |
| 初回の失敗 | 有効なデータがない。再試行と運用確認を行う。 |
| 成功後の失敗 | 以前の表示を保持し、その時刻を確認する。 |
| アプリが見つからない | ID・リンクを確認する。既知の削除済みアプリとは異なる。 |
| 削除済みアプリ | IDと履歴は残る。有効なスナップショットで不在を確認済み。 |

## 状態、言語、問い合わせ

`AVAILABLE`、`UNAVAILABLE`、`NO_METRICS`、`REMOVED`は運用状態です。鮮度、理由、計算可否は別の情報です。利用可能でも炭素係数がない場合があり、利用不可でも有効な履歴は残ります。詳細画面では運用状態、メトリクス、環境結果、時系列、期間別の寄与を確認できます。[APIリファレンス](../reference/api)と[方法論](../product/methodology)を参照し、欠損・失敗・ゼロを区別してください。

言語選択は8言語に対応し、このブラウザーに保存されます。言語変更でIDや観測時点は変わりません。

問題報告には環境、ID、条件、タイムゾーン付き日時、操作、期待結果と実際の結果を含めます。画像に秘密情報や個人データを載せず、[運用](../operations)も確認します。

## テーマの設定

ナビゲーションの設定で **ダークモード** スイッチを使用します。オフでライト、オンでダークになります。初回アクセス時は、スイッチを操作するまで使用中の変更も含めてシステムの外観に従います。その後は明示的な選択が優先されます。この画面にはシステムへの追従に戻す操作はありません。

設定はカタログ、詳細、共通レイアウトに適用され、フィルターやデータは変更しません。このブラウザーの `greener-theme` に保存され、次回も使用されます。保存がブロックされてもセッション中は選択できますが、再読み込みで失われる場合があります。
