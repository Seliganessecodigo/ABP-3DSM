# 利用ガイド

環境サマリーから注目するアプリを選び、詳細を開きます。履歴で期間を調べ、方法論で推定の根拠を確認します。比較する前に必ずカバー率を考慮してください。

## アプリを探す {#catalog}

カタログで名前、識別子、地域を検索し、状態で絞り込みます。表のページを切り替えてアプリを開きます。該当しない場合はフィルターを確認してください。ページのアドレスに検索とページ選択が残るため、共有や再開に利用できます。

## ダッシュボードを読む {#dashboard}

ダッシュボードで24時間、7・30・90日、地域、状態を選びます。エネルギー、排出量、カバー率、状態別件数を確認できます。排出割合は棒またはドーナツ図で表示します。表の検索・フィルター・影響順の並べ替えは行だけを変更し、合計は選択した集計範囲を維持します。

時系列ではエネルギーとCO₂eを切り替えたり、期間別の表を開いたりできます。24時間の範囲は時間単位、それ以外は日単位で集計します。期間はUTC基準で、指標と同じフィルターを使用します。欠損区間には値を表示しません。

## 詳細を調べる {#detail}

詳細を開き、識別情報、所在地、状態、更新時刻を確認します。同じ期間のメトリクスと環境指標を調べます。記録された方法論は計算で使用したモデル、パラメーター、炭素係数を示し、結果を変更しません。都市が不明でもほかの所在地情報は利用できます。

等価排出係数は、排出量を計算できたエネルギー量で重み付けした地域係数の要約です。計算の説明ではこのエネルギーを使用するため、一部の期間で係数が欠ける場合は総エネルギー量より少なくなることがあります。係数の詳細を開くと、地域別の値と出典を確認できます。

## 履歴を調べる {#history}

履歴でアプリ、期間、時・日・月・年の集計単位を選びます。フィルターとページ切替で区間を探し、内訳を開いて含まれた観測と除外を調べます。タイムゾーンは日付表示だけを変更し、集計はUTCのままです。詳細の重ね合わせは同じアプリの直前の同じ長さの期間と比較します。

## 再計算プレビューと比較する {#preview}

再計算プレビューでアプリと日付を選び、原本を現行モデルと観測地域の現在の炭素係数による推定と比較します。終了日はUTCの一日全体を含みます。上限は30日、10,000観測です。プレビューは保存されず履歴を変更しません。割合の差は単位とカバー率が一致し、原本が正の値の場合に表示します。

## 分析を自分用に設定する {#preferences}

方法論ではエネルギー、排出量、カバー率、分析のタブを確認できます。デモには画面上で明示した例示データを使用します。ログインすると表示しきい値と初期期間・集計単位を保存できます。各自の設定だけが変更され、計算や全体設定は保たれます。保存が競合したら設定を読み直して再試行してください。分析アドレスで既に選択した項目が保存設定より優先されます。

## ログインする {#access}

カタログ、ダッシュボード、環境参照はログイン不要です。設定の保存にはメールとパスワード、または有効化されたGoogleと招待によるアカウント連携を利用します。管理者は認証アプリの6桁コードも確認します。ページを再読み込みすると画面のセッションが終了し、再ログインが必要です。管理権限はアカウントの役割によって決まります。

## 言語と表示 {#appearance}

セレクターから12言語を選べます。選択はこのブラウザーに保存されます。ダークモードで外観を変更でき、明示的に選ぶまではシステムに従います。保存が禁止されていると再読み込み後に失われる場合があります。言語によって日付と数値の書式が変わりますが、観測時刻そのものは変わりません。

## データを読み取る {#data}

ゼロは有効な観測がその値を裏付けることを意味します。欠損は利用できるデータがないことで、消費ゼロではありません。更新に失敗すると直前の有効値を元の時刻とともに保持する場合があります。判断前に更新時刻とカバー率を確認してください。画面は各試行後60秒で再照会しますが、毎回新しい測定があるとは限りません。

| 状態 | 意味 |
| --- | --- |
| 利用可能 | 利用できるメトリクスが返りました。 |
| 利用不可 | 今回の試行が失敗しました。有効な履歴は残る場合があります。 |
| メトリクスなし | アプリは既知ですが、今回利用できるメトリクスがありません。 |
| 削除済み | 元のカタログで不在を確認しました。識別情報と履歴は保持します。 |

カバー率は有効な観測で裏付けられる期間の割合です。エネルギーと排出量は別々に計算され、炭素係数がなくてもエネルギー推定が得られる場合があります。期間、単位、カバー率が対応した結果を比較してください。低いカバー率は部分的な分析を示し、消費減少の証明にはなりません。

## 診断 {#support}

問題報告にはアプリ、期間、フィルター、タイムゾーン付き時刻、操作を記載し、期待結果と実際の結果を説明してください。認証情報や個人データを含まない画面キャプチャも役立ちます。
