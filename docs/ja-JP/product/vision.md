# ビジョンと範囲

GreenERはアプリを監視し、推定エネルギー消費と二酸化炭素換算排出量（CO₂e）を理解するための製品です。指標、所在地、履歴をまとめ、デジタルサービスの環境影響を調べる際に役立ちます。

## 対象読者 {#readers}

| 対象 | 必要性 |
| --- | --- |
| インフラ管理 | アプリを把握し、環境の変化を追跡する。 |
| 環境・運用分析 | 対象期間の消費、排出、データ品質を調べる。 |
| 開発・評価 | 製品の動作を確認し、結果を再現する。 |

## 分析の進め方 {#journey}

環境サマリーから注目するアプリを選び、詳細を開きます。履歴で期間を調べ、方法論で推定の根拠を確認します。比較する前に必ずカバー率を考慮してください。

## 利用上の制限 {#limits}

簡略モデルが観測区間のCPU、メモリ、ディスク、ネットワークからエネルギーを推定します。推定電力を時間に応じてエネルギーへ変換し、地域の炭素強度を掛けて排出量を求めます。係数は学術モデルのもので、電力実測や公式地域係数ではありません。結果は使用した方法論と係数を保持します。

カバー率は有効な観測で裏付けられる期間の割合です。エネルギーと排出量は別々に計算され、炭素係数がなくてもエネルギー推定が得られる場合があります。期間、単位、カバー率が対応した結果を比較してください。低いカバー率は部分的な分析を示し、消費減少の証明にはなりません。

## 今後の拡張 {#planned}

アプリ間の専用比較、他地域でのシミュレーション、ユーザー・役割管理全体、パスワード自己復旧、監視全体の操作を計画しています。CSV出力の範囲は未確定です。エネルギーや排出量での並べ替えは既に利用できます。優先度はバックログで管理し、この文書では提供日を定めません。
