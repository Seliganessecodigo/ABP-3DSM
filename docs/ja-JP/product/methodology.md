# 方法論とデータの意味

証拠の意味を保持します。不在、エラー、古いデータはゼロではありません。エネルギーはバージョン付きパラメーターを持つ簡略モデルで推定し、実際の電力測定値ではありません。パラメーターは公式の地域係数ではありません。CO₂e換算関係は#49/#53で実装済みです。

## 用語と単位

| 用語 | 意味 |
| --- | --- |
| アプリケーション | 安定したID。名前や所在地は変更可能。 |
| 観測・収集 | アプリと区間に紐づく永続化済みメトリクス。 |
| サイクル | 検出、照合、収集の実行。単独の測定ではない。 |
| エネルギー | 期間中の累積量、kWh。電力とは異なる。 |
| 炭素強度 | 情報源の地域係数、gCO₂e/kWh。 |
| CO₂e | 単位と係数を識別できる等価排出量。 |
| カバレッジ | 要求期間のうち有効な証拠で裏付けられた割合。エネルギーとCO₂eを別々に算定します。 |
| Stale | 保持された過去の有効観測。今回の成功ではない。 |

集約元の契約はCPUを%、メモリー・ディスク・ネットワークをGBで定義します。kWhではなく、変換にはモデル、係数、前提の文書化が必要です。

## 時間と出所

測定元は測定タイムスタンプを公開しません。GreenERは受信時刻を記録し、`[receivedAt - collection_interval_seconds, receivedAt]`を導出します。これは元の測定時刻を証明しません。

最終試行、最終有効観測、登録更新は異なります。炭素係数の取得時刻も公式の有効期間を証明しません。スナップショットは値、内部ID、契約、取得時刻を保存します。非公開の文献情報と有効期間は不明のままです。

## 環境データの時間規則

クエリはタイムゾーン明示のISO timestampをUTC正規化し、[from,to)を使います。UTC時・日・月・年bucketは部分的な端も含め重複分のみ数えます。24h/7d/30d/90dは正確な長さの移動期間で、KPIと系列は同じ基準時刻を共有します。上限10,000点。超過は切り詰めや粒度変更をせず拒否します。系列は保存済み結果を按分し、生の観測値を再計算しません。重複は最新collectedAt、次にID辞書順で解決し、指標を支えない場合はフォールバックせず欠損を保ちます。追加の丸めは行わず、カバレッジと元snapshotを分けて保持します。

## エネルギーと排出量

実装済みの次元関係：

    CO₂e [g] = エネルギー [kWh] × 炭素強度 [gCO₂e/kWh]

説明専用の例：2 kWh × 100 gCO₂e/kWh = 200 gCO₂e = 0.2 kgCO₂e。承認済み係数や製品の測定値ではありません。CPU等からエネルギーを求めるモデルも定義していません。

係数不在でも有効なエネルギーは有効ですが、CO₂eは計算できない場合があります。ゼロには有効な証拠が必要です。

## 履歴とシナリオ

| 結果 | 規則 |
| --- | --- |
| 元の結果 | 観測、設定、方法論、係数を保存する。 |
| 地域シミュレーション | エネルギーを固定し、別地域の係数を公式結果と分けて評価する。 |

合計、ランキング、比較には互換性のある期間とカバレッジが必要です。欠損はゼロにせず、割合には有効な分母が必要です。承認済みの時間規則は上記のとおりです。永続化ではエネルギー、グラム単位の排出量、係数は小数8桁、0から1の割合であるカバレッジは小数4桁です。中間丸めは行わず、JSON snapshotは元の表現を保持します。

## 方法論とデータ — simplified-energy v1

実装モデルは`simplified-energy`版`1`。CPU 100%で100 W、メモリ0.375 W/GB、ディスク0.01 W/GB、ネットワーク0.02 W/GB。簡略モデルのパラメーターであり、電力実測や公式地域係数ではありません。電力は合算、エネルギー = W × 時間 / 1000、CO₂e[g] = kWh × gCO₂e/kWh。snapshotに方法と係数を保持し、現在係数を使うプレビューで原本を変更しません。

`/administration/calculations`でアプリと日付を選び原本とプレビューを比較。終了日はUTCの一日全体を含み、APIは`[from,to)`。公開操作で現行モデルと過去地域の現在係数を使用し、保存しません。上限30日・10,000観測。応答は`original`、`preview`、`warnings`、`status`（`available`、`empty`、`partial`）。係数障害でも算出可能なエネルギーを保持。百分率は同じ単位・カバー率と正の基準値が必要です。

`/methodology`にエネルギー、排出量、カバー率、分析の4タブと例示データ。ログインした各役割は自分のタブだけ保存し、楽観的リビジョン競合は409。表示しきい値は全体設定・計算・外部通知を変更しません。保存した期間/粒度は詳細URLで未指定の場合のみ適用。記録済み方法論は`/services/:id/methodology`と選択時の`collectionId`で保持します。
