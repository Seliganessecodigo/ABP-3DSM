# Engenharia e qualidade do GreenER

O GreenER reúne um conjunto amplo de funcionalidades com verificações técnicas que atravessam interface, API e persistência. A qualidade está apoiada em contratos explícitos, testes automatizados, organização por responsabilidades e rastreabilidade dos indicadores ambientais.

## Produto integrado

Catálogo, dashboard, detalhe, histórico, ranking, comparação e simulação regional compartilham os dados persistidos pela API. Filtros e contexto de navegação apoiam a investigação do resumo até os intervalos e resultados de uma aplicação. Preferências pessoais, contas e controles administrativos completam os fluxos de uso.

## Verificação em camadas

A CI executa verificações do site, frontend e backend, aplica migrations em PostgreSQL temporário e exercita fluxos no navegador com a API real e fontes HTTP controladas. O SonarQube Cloud verifica o código novo com cobertura mínima de 80%, duplicação máxima de 3%, ratings A e revisão de todos os security hotspots.

A documentação também faz parte da engenharia: conteúdo, links, exemplos e contratos são verificados automaticamente entre os 12 idiomas. O código e as evidências da base 240a2c2 permitem reproduzir e examinar as afirmações deste registro.
