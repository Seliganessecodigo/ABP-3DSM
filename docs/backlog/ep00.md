# EP00 — Fundações técnicas, qualidade e processo de entrega

Agrupa requisitos transversais de tecnologia, arquitetura, dados, segurança, operação, falhas e acessibilidade. As tasks filhas representam entregas técnicas verificáveis; a qualidade continua valendo em cada mudança posterior.
