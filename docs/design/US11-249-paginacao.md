# Paginação da tabela — US-11 / issue #249

O frame **US11 / Desktop / Evolução · Tabela** no arquivo GreenER foi ajustado para apresentar a paginação com controles anterior/próxima nas extremidades e o indicador central `Página 1 de 21`. Foram reaproveitadas as instâncias compartilhadas existentes, com os botões no estado padrão e espaçamento automático. Rótulos e estilo seguem a identidade visual e o idioma do produto.

A captura `US11-249-paginacao.jpg` registra o frame no contexto da tela. O indicador é uma amostra visual estática; esta alteração não implementa comportamento de paginação no produto.
