## Recorrido y criterios de validación

| Historia | Escenario y resultado esperado |
| --- | --- |
| US-16 | Ocho idiomas, identidad/contexto/formato coherentes, sin cambiar instantes. |
| US-17 | Claro/oscuro/sistema, foco, contraste y estados legibles. |
| US-18 | Lectura pública; cambios solo con JWT/permisos verificados por backend. |
| US-19 | Parámetros y pausa/retoma/ejecución autorizados, con versiones/historial. |
| US-20 | Cuentas/papeles y recuperación separada, respuesta genérica, token inválido/expirado/usado. |

Idioma no es permiso. Matriz, bootstrap, sesión y contraseña pendientes. Handoff debe cubrir estados, mobile y teclado. Configuración no reescribe resultados pasados.
