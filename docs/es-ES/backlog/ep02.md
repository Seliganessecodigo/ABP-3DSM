## Recorrido y criterios de validación

| Historia | Escenario y resultado esperado |
| --- | --- |
| US-02 | ID nuevo una vez; primera ausencia de snapshot completo válido confirma retirada; retorno conserva identidad/historial, sin rellenar laguna. |
| US-03 | Estado, motivo y hora; distinguir disponibilidad, frescura, calculabilidad y usar texto/icono además de color. |
| US-04 | Actualizar sin reload ni perder filtros/página/aplicación; respuesta vieja no reemplaza contexto nuevo; polling separado de recopilación. |
| US-05 | Fallo de aplicación/fuente no invalida éxitos; conservar última observación y recuperar con evidencia válida. |

Payload inválido, timeout y error no confirman retirada. 404 de métricas es ambiguo. Integración/persistencia son previas; timeout/retry/concurrencia/retrasos necesitan política aprobada.
